# 网页视频播放窗口 - 智能主视频控制工具

> 智能识别主视频自动播放，悬浮控制条支持精确跳转、长按快进、倍速控制

## 核心功能

### 1. 智能主视频识别

三重筛选逻辑，精准识别唯一主视频：
- **尺寸过滤** - 宽度≥280px，高度≥160px
- **可视性检查** - 在视口内且未隐藏
- **数量判定** - 唯一则选中，多个选最大

### 2. 自动播放

- 页面加载后自动识别并播放主视频
- 有声播放被阻止时自动尝试静音播放
- 防重复触发，最多重试8次

## 控制按钮说明

### 第一行：控制栏

| 按钮 | 点击效果 | 长按效果 |
|------|----------|----------|
| `« 1min` | 后退60秒 | 3倍速持续后退 |
| `« 10s` | 后退10秒 | 3倍速持续后退 |
| `10s »` | 前进10秒 | 3倍速持续前进 |
| `1min »` | 前进60秒 | 3倍速持续前进 |
| `速度▼` | 切换倍速 | - |
| `▶/⏸` | 播放/暂停 | - |

**倍速选项**: 0.25x / 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x / 4x

### 第二行：进度条

- 显示当前时间和总时长
- 点击任意位置跳转
- 拖拽进度点精确控制

### 右下角：开关按钮

- **▼** - 面板显示中
- **▲** - 面板已隐藏

## 技术特性

- **DOM保护** - MutationObserver 防止面板被移除
- **移动端适配** - 支持触摸事件
- **状态持久化** - 保存开关状态
- **透明背景** - 不遮挡视频内容
- **自动检测** - 无视频时自动隐藏

---

## 注意事项

1. 仅对 `<video>` 标签生效
2. 需要 Tampermonkey 的 `GM_setValue` 和 `GM_getValue` 权限
3. 支持SPA应用，视频动态加载后自动识别
