## 核心功能

### 1. 智能主视频识别

**问题**: 网页经常同时存在多个视频（主播放器 + 侧边预览 + 缩略图），直接 `querySelector('video')` 会随机抓到预览视频。

**解决方案**: 三重筛选逻辑，精准识别唯一主视频

```
┌─────────────────────────────────────────────────────────┐
│  主视频识别流程                                          │
│                                                         │
│  所有视频 → 尺寸过滤 → 可视性检查 → 数量判定 → 主视频   │
│                                                         │
│  步骤1: 尺寸过滤                                         │
│  ├─ 宽度 ≥ 280px (可配置)                                │
│  └─ 高度 ≥ 160px (可配置)                                │
│                                                         │
│  步骤2: 可视性检查                                       │
│  ├─ 在浏览器视口内                                       │
│  ├─ display ≠ none                                      │
│  └─ visibility ≠ hidden                                 │
│                                                         │
│  步骤3: 数量判定                                         │
│  ├─ 恰好1个 → 认定为主视频 ✓                             │
│  ├─ 多个 → 选择面积最大的                                │
│  └─ 0个 → 不执行操作                                     │
└─────────────────────────────────────────────────────────┘
```

### 2. 自动播放主视频

| 特性 | 说明 |
|------|------|
| **延迟检测** | 页面加载后延迟500ms执行，等待视频元素渲染完成 |
| **轮询重试** | 未找到主视频时最多重试5次，间隔500ms |
| **防重复触发** | 使用 `dataset.autoPlayTriggered` 标记，避免重复调用 `.play()` |
| **浏览器兼容** | 捕获Promise错误，有声播放被阻止时自动尝试静音播放 |

### 3. 悬浮控制面板

```
┌─────────────────────────────────────────────────────────────┐

│  │                                                       │  │
│  │  « 1min │ « 30s │ « 5s │ 5s » │ 30s » │ 1min »      │  │
```

## 功能详细说明

### 跳转按钮区 (第一行)

| 按钮 | 功能 | 点击效果 | 长按效果 |
|------|------|----------|----------|
| `« 1min` | 后退60秒 | 跳转-60秒 | 3倍速持续后退 |
| `« 30s` | 后退30秒 | 跳转-30秒 | 3倍速持续后退 |
| `« 5s` | 后退5秒 | 跳转-5秒 | 3倍速持续后退 |
| `5s »` | 前进5秒 | 跳转+5秒 | 3倍速持续前进 |
| `30s »` | 前进30秒 | 跳转+30秒 | 3倍速持续前进 |
| `1min »` | 前进60秒 | 跳转+60秒 | 3倍速持续前进 |

**长按特性**:
- 按住按钮不放，以 **3倍速** 持续跳转
- 每200ms执行一次跳转
- 松开后恢复原始播放速度
- 支持鼠标和触摸操作

### 工具栏 (第二行)

#### 左侧：倍速控制

```
[速度 ▼] 下拉选择器
```

可选倍速：0.25x / 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x / 4x

**说明**: 选择后立即生效，仅作用于主视频

#### 中间：时间显示

```
[00:05 / 01:20]
     ↑
  当前时间 / 总时长
```

- 实时显示，每300ms更新
- 格式：`MM:SS` 或 `HH:MM:SS`（超过1小时）

#### 右侧：开关按钮

```
[⏸] 或 [▶]
```

- `⏸` - 控制面板已显示
- `▶` - 控制面板已隐藏
- 点击切换显示/隐藏状态

## 配置说明

在脚本顶部 `CONFIG` 对象中可自定义：

```javascript
const CONFIG = {
  defaultEnabled: true,           // 默认是否启用
  panelWidth: '94%',              // 面板宽度
  borderRadius: '18px',           // 圆角大小
  debugBg: "transparent",         // 面板背景色
  buttonColor: 'rgba(40, 40, 40, 0.55)',     // 按钮背景色
  accentColor: 'rgba(80, 110, 190, 0.55)',   // 强调色
  textColor: 'rgba(240, 240, 240, 0.96)',    // 文字颜色
  fontSize: '14px',               // 字体大小
  gap: '8px',                     // 按钮间距
  
  // 主视频筛选阈值
  minWidth: 280,                  // 最小宽度(px)
  minHeight: 160,                 // 最小高度(px)
  
  // 自动播放
  autoPlayEnabled: true,          // 是否启用自动播放
  autoPlayDelay: 500,             // 延迟检测时间(ms)
  autoPlayMaxRetries: 5           // 最大重试次数
};
```

### 阈值调整建议

| 场景 | minWidth | minHeight | 说明 |
|------|----------|-----------|------|
| **PC端通用** | 280 | 160 | 默认值，适合大多数网站 |
| **移动端** | 200 | 120 | 手机屏幕较小，适当降低 |
| **严格过滤** | 400 | 225 | 过滤更多小预览视频 |
| **宽松模式** | 160 | 90 | 保留较小视频 |

## 使用场景

### 场景1: 自动播放主视频
1. 打开包含视频的网页
2. 脚本自动识别主视频并播放
3. 无需手动点击，跳过预览干扰

### 场景2: 精确跳转到视频某一段
1. 使用跳转按钮快速定位
2. 点击 `« 30s` 后退30秒
3. 长按 `5s »` 持续快进

### 场景3: 慢速学习复杂内容
1. 点击速度下拉框
2. 选择 `0.5x` 或 `0.75x`
3. 视频以慢速播放，便于理解

### 场景4: 快速浏览视频
1. 选择 `2x` 或 `4x` 倍速
2. 配合跳转按钮快速定位
3. 找到目标内容后恢复正常速度

## 技术特性

| 特性 | 说明 |
|------|------|
| **智能识别** | 三重筛选逻辑，精准识别主视频 |
| **自动播放** | 延迟检测 + 轮询重试 + 防重复触发 |

## 注意事项

1. **视频检测**: 仅对 `<video>` 标签生效，Flash/iframe嵌入视频不支持
2. **权限要求**: 需要 Tampermonkey 的 `GM_setValue` 和 `GM_getValue` 权限
3. **多视频页面**: 自动识别并只操作主视频，忽略预览小视频
4. **动态加载**: 支持SPA应用，视频动态加载后自动识别
5. **自动播放限制**: 现代浏览器可能阻止有声自动播放，脚本会自动尝试静音播放
