# 视频悬浮精确控制工具（智能主视频版）

> 智能识别主视频自动播放，两行紧凑控制条支持精确跳转、持续前进、倍速控制

## 核心功能

### 1. 智能主视频识别

自动识别页面中的主视频，过滤掉预览小视频、缩略图、hover 预览等干扰项：

- **尺寸过滤** — 宽度 ≥ 280px，高度 ≥ 160px
- **可视性检查** — 在视口内且未被隐藏，`getBoundingClientRect` 异常时自动使用 `offsetWidth/offsetHeight` 备选
- **数量判定** — 唯一候选则直接选中，多个候选时选择面积最大的
- **节流缓存** — 300ms TTL 缓存，减少 `getBoundingClientRect` 调用，提升性能

### 2. 自动播放

- 页面加载后延迟 200ms 自动识别并播放主视频
- 有声播放被浏览器阻止时，自动降级为静音播放
- 防重复触发机制，最多重试 8 次（间隔 300ms）
- SPA 路由切换或 DOM 变化时自动重新检测

### 3. 悬浮控制面板

固定在页面底部中央，宽度 94%，最大 460px，半透明背景不遮挡内容。

## 控制按钮说明

### 第一行：控制栏

| 按钮 | 点击效果 | 长按效果 |
|------|----------|----------|
| `« 1min` | 后退 60 秒 | 无 |
| `« 10s` | 后退 10 秒 | 无 |
| `10s »` | 前进 10 秒 | 无 |
| `1min »` | 前进 60 秒 | 无 |
| `1x ▼` 倍速按钮 | 弹出上拉菜单选择倍速 | — |
| `▶ / ⏸` | 播放 / 暂停 | — |
| `》` | 2 倍速持续前进 / 取消 | — |

**可用倍速**: 0.25x / 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x / 4x

### 倍速按钮说明

- 按钮文本直接显示当前倍速（如 `1x`、`1.5x`）
- 点击弹出上拉菜单，选择后自动关闭并更新按钮文本
- 点击页面其他区域自动关闭菜单
- 视频倍速变化时按钮文本自动同步

### 持续前进按钮说明

- 首次点击：设置 2 倍速，每 200ms 前进 10 秒，按钮高亮
- 再次点击：清除定时器，恢复原始倍速，按钮恢复
- 面板切换或销毁时自动清理定时器

### 第二行：进度条

- 左侧显示当前时间，右侧显示总时长
- 点击任意位置跳转至对应时间点
- 拖拽进度圆点精确控制，**抬起时才执行 seek**，避免视频画面抖动
- 支持鼠标和触摸操作

### 右下角：开关按钮

- **▼** — 面板显示中（点击可隐藏）
- **▲** — 面板已隐藏（点击可显示）
- 开关状态自动保存，刷新页面后保持

## 技术特性

- **DOM 保护** — `MutationObserver` 监控面板是否被意外移除，自动重新插入并恢复原有状态（透明度、pointerEvents 等）
- **面板稳定性增强** — 用户手动开启面板后不再自动隐藏；`getMainVideo` 增加容错，避免因浏览器原生控件交互导致误判
- **移动端适配** — 完整支持触摸事件（`touchstart` / `touchmove` / `touchend`）
- **状态持久化** — 使用 `GM_setValue` / `GM_getValue` 保存开关状态
- **半透明背景** — 不遮挡视频内容
- **SPA 兼容** — 监听 `popstate`、拦截 `pushState` / `replaceState`，适配单页应用路由切换
- **动态检测** — `MutationObserver` 监听 DOM 变化，视频动态加载后自动识别
- **DOM 缓存优化** — 缓存控制面板元素引用，减少重复查询；切换状态时自动刷新缓存

## 配置项

脚本顶部 `CONFIG` 对象可自定义以下参数：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `defaultEnabled` | `true` | 默认是否启用控制面板 |
| `panelWidth` | `'94%'` | 面板宽度 |
| `minWidth` | `280` | 主视频最小宽度阈值（px） |
| `minHeight` | `160` | 主视频最小高度阈值（px） |
| `autoPlayEnabled` | `true` | 是否启用自动播放 |
| `autoPlayDelay` | `200` | 首次自动播放延迟（ms） |
| `autoPlayRetryInterval` | `300` | 自动播放重试间隔（ms） |
| `autoPlayMaxRetries` | `8` | 自动播放最大重试次数 |

## 注意事项

1. 仅对 `<video>` 标签生效，不支持 `<iframe>` 嵌入的视频
2. 需要 Tampermonkey 的 `GM_setValue` 和 `GM_getValue` 权限
3. 浏览器可能阻止带声音的自动播放，此时会尝试静音播放
4. 支持 SPA 应用，视频动态加载后自动识别
5. 点击浏览器原生视频控件时面板保持稳定，不会意外消失
