# 📖 小说下载器 - 三站整合版

## 基本信息

| 项目 | 内容 |
|------|------|
| **脚本名称** | 小说下载器-三站整合版 |
| **版本** | 1.0 |
| **类型** | Tampermonkey 用户脚本 |
| **运行时机** | document-end |
| **匹配规则** | `*://*/*`（所有网站） |

## 功能概述

适配三个特定小说网站，支持智能验证码处理、多站点自动识别、批量章节下载、进度缓存和多种内容提取策略的整合版小说下载器。

## 核心功能

### 1. 三站点适配
- **站点A/B/C**: 自动识别并适配三种不同小说网站结构
- **自动识别**: 根据页面链接和结构自动匹配对应站点

### 2. 智能验证码处理
- **自动检测**: 请求返回内容中检测验证码关键词
- **弹窗验证**: 打开新标签页让用户手动完成验证
- **验证按钮**: 提供"验证完成"和"跳过"按钮
- **自动重试**: 验证完成后自动重新请求原始URL

### 3. 多种内容提取器
- **text提取器**: 克隆节点后移除干扰元素，提取纯文本
- **div-line提取器**: 按div分行提取内容
- **p-tag提取器**: 按p标签提取段落内容
- **c-content提取器**: 特定站点专用提取策略
- **fallback提取器**: 兜底提取方案

### 4. 下载优化
- **随机延迟**: 每次请求添加随机延迟，模拟人类行为
- **重试机制**: 默认重试3次
- **缓存系统**: 使用 Map 缓存已下载章节
- **进度保存**: 使用 GM_setValue 保存下载进度
- **取消功能**: 支持随时取消下载任务

### 5. 章节扫描
- **多站点扫描**: 同时扫描三个站点的章节链接
- **智能匹配**: 根据站点特征匹配对应章节
- **进度显示**: 实时显示下载进度

## 运行逻辑

### 初始化流程
```
页面加载 → loadProgress() → createUI() → registerMenu()
```

### 下载流程
```
扫描章节 → 按站点分类 → 遍历下载 → 缓存检查 → 请求页面 → 验证码检测 → 提取内容 → 保存进度
```

### 验证码处理流程
```
检测验证码 → 打开新标签页 → 显示验证按钮 → 等待用户操作 → 验证完成 → 重新请求
```

## 技术细节

### 配置参数
```javascript
{
  completed: 0,           // 已完成章节数
  resultMap: {},          // 章节结果映射
  minTxtLength: 100,      // 最小文本长度
  retryCount: 3,          // 重试次数
  cancel: false,          // 取消标志
  chapterList: []         // 章节列表
}
```

### 缓存系统
- 使用 `Map` 对象缓存已下载章节
- 键：章节URL，值：章节内容

### 进度持久化
- 使用 `GM_setValue` 保存下载进度
- 页面刷新后自动恢复

## 使用方法

1. 打开支持的小说网站章节列表页
2. 等待脚本自动识别站点和章节
3. 点击下载按钮开始批量下载
4. 如遇验证码，在新标签页完成验证后点击"验证完成"
5. 等待下载完成，自动导出文件
