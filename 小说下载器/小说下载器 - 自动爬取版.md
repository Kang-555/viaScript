# 📖 小说下载器 - 自动爬取版

## 基本信息

| 项目 | 内容 |
|------|------|
| **脚本名称** | 小说下载器-自动爬取版 |
| **版本** | 1.0 |
| **类型** | Tampermonkey 用户脚本 |
| **运行时机** | document-end |
| **匹配规则** | `*://*/*`（所有网站） |

## 功能概述

在小说正文页自动提取文本内容，根据"下一章"链接循环爬取所有章节，支持自动/手动两种模式，可导出为 TXT 文件。

## 核心功能

### 1. 自动爬取模式
- 点击"开始"按钮后自动请求当前页面
- 提取章节标题和正文内容
- 自动查找"下一章"链接并继续爬取
- 请求间隔 1500ms，避免被封禁
- 检测到已爬取的章节自动停止

### 2. 手动下滑模式
- 自动模式找不到下一章链接时自动切换
- 监听页面滚动事件
- 向下滚动时自动提取并保存当前章节
- 适合需要手动翻页的小说网站

### 3. 内容提取
- **标题提取优先级**: `h1` → `.title` → `.chapter-title` → `h2` → `h3` → `.xs-title` → `document.title`
- **正文提取优先级**: `article#chapterContent` → `#content` → `.content` → `.article` → `.read-content` → `.chapter-content` → `.content_txt`
- 自动移除广告、脚本、样式等无关元素
- 智能清理多余空行

### 4. 下一章链接查找
- **选择器匹配**: `.next a` → `.next-chapter a` → `#next a` → `a[href*="next"]` → 等
- **文本匹配**: 查找包含"下一章"或"下一"的链接

### 5. 数据管理
- **标签页隔离**: 每个标签页使用独立存储空间，互不影响
- **持久化存储**: 使用 `GM_setValue` 保存章节数据
- **去重机制**: 通过 URL 判断章节是否已爬取
- **手动清空**: 提供清空按钮手动清除数据

### 6. 导出功能
- **导出全部**: 将所有爬取的章节导出为 TXT
- **导出选中**: 仅导出勾选的章节
- **格式规范**: 自动排版，包含小说标题、章节数、分隔线

## 使用方法

### 安装
1. 安装 Tampermonkey 浏览器扩展
2. 点击脚本文件，Tampermonkey 会自动识别并安装
3. 或手动创建新脚本，将代码粘贴进去

### 使用步骤
1. 打开小说网站的任意章节页面
2. 点击页面右侧中间的 **📖 自动爬取** 按钮
3. 在弹出的面板中点击 **▶️ 开始** 按钮
4. 等待爬取完成（可实时查看进度）
5. 点击 **💾 导出全部** 或 **📤 导出选中** 下载 TXT 文件

## 技术细节

### 存储结构
```javascript
{
  tabId: "tab_时间戳_随机串",  // 标签页唯一标识
  chapters: [
    {
      title: "第一章 标题",
      content: "正文内容...",
      url: "https://...",
      nextUrl: "https://...",
      timestamp: 1234567890,
      isManual: false  // 是否手动模式保存
    }
  ],
  selectedChapters: Set,  // 选中导出的章节索引
  currentChapterIndex: 0,
  delay: 1500,  // 请求间隔（毫秒）
  minContentLength: 100  // 最小内容长度
}
```

### 存储键格式
```
autoNovelCrawler_chapters_tab_1234567890_abc123
```

### 请求配置
- **超时时间**: 15000ms
- **请求头**: 模拟浏览器 User-Agent
- **Referer**: 当前页面 URL
- **字符编码**: UTF-8

### 容错机制
- 内容为空或过短（<100字符）自动停止
- 章节已存在（URL 重复）自动停止
- 未找到下一章链接自动切换手动模式
- 网络请求失败/超时自动停止

## 注意事项

1. **标签页隔离**: 每个标签页的数据完全独立，切换标签页不会互相影响
2. **请求频率**: 默认 1500ms 间隔，可在代码中修改 `this.config.delay`
3. **内容验证**: 章节内容必须大于 100 字符才会被保存
4. **跨域请求**: 使用 `GM_xmlhttpRequest` 实现跨域请求
5. **广告过滤**: 自动移除 `.ad`, `.ads`, `.advertisement` 等元素

## 适用场景

- ✅ 支持"下一章"链接的小说网站
- ✅ 需要批量下载整本小说
- ✅ 网站有反爬机制（延迟请求）
- ✅ 需要手动翻页的小说网站（手动模式）
- ❌ 需要登录才能阅读的小说
- ❌ 使用 JavaScript 动态加载内容的网站（部分支持）
