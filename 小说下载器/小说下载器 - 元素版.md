# 小说下载器 - 元素版

## 基本信息

| 项目 | 内容 |
|------|------|
| **脚本名称** | 小说下载器-元素版 |
| **版本** | 5.0 |
| **类型** | Tampermonkey 用户脚本 |
| **运行时机** | document-end |
| **匹配规则** | `*://*/*`（所有网站） |

## 功能概述

适配特定小说网站结构，带状态面板、章节选择器、并发下载、自适应延迟和进度恢复的增强版小说下载器。

## 核心功能

### 1. 双站点适配
- **站点A/B**: 自动识别并适配两种不同小说网站结构
- **自动识别**: 根据页面链接自动匹配对应站点

### 2. 章节选择器
- **全选模式**: 下载所有章节
- **范围模式**: 指定起始和结束章节范围
- **前N章模式**: 仅下载前N章
- **章节列表**: 可视化显示所有章节供勾选

### 3. 并发下载
- **可配置并发数**: 默认20个并发任务
- **速率限制**: 可设置每分钟最大下载数
- **自适应延迟**: 根据下载情况自动调整延迟
- **随机延迟**: 每次请求添加随机延迟（1000-2000ms）

### 4. 进度管理
- **进度保存**: 使用 GM_setValue 保存下载进度
- **断点续传**: 刷新页面后自动恢复进度
- **进度面板**: 实时显示下载进度和当前章节
- **取消功能**: 支持随时取消下载任务

### 5. 下载优化
- **缓存系统**: 使用 Map 缓存已下载章节
- **重试机制**: 失败后自动重试
- **内容验证**: 验证内容长度确保下载成功

### 6. 导出功能
- **自动导出**: 下载完成后自动生成TXT文件
- **格式规范**: 包含小说标题、章节序号、正文内容
- **进度清理**: 导出完成后自动清除进度数据

## 运行逻辑

### 初始化流程
```
页面加载 → loadProgress() → createUI()
```

### 下载流程
```
点击"下载小说" → scanChapters() → showChapterSelector() → 选择模式 → startDownload() → 并发下载 → saveFile()
```

### 并发调度流程
```
scheduleNext() → 检查速率限制 → 检查并发数 → downloadChapter() → 更新进度 → 继续下一章节
```

## 技术细节

### 配置参数
```javascript
{
  completed: 0,           // 已完成章节数
  resultMap: {},          // 章节结果映射
  chapterList: [],        // 章节列表
  isDownloading: false,   // 是否正在下载
  cancel: false,          // 取消标志
  maxConcurrency: 20,     // 最大并发数
  delay: 0,               // 基础延迟（毫秒）
  maxDlPerMin: 0,         // 每分钟最大下载数
  adaptiveDelay: true,    // 自适应延迟
  retryCount: 3           // 重试次数
}
```

### 下载模式
1. **全部下载**: 下载所有章节
2. **范围下载**: 指定起始和结束章节
3. **前N章**: 仅下载前N章

## 使用方法

1. 打开支持的小说网站目录页
2. 点击 **下载小说** 按钮
3. 选择下载模式和参数
4. 点击 **开始下载**
5. 等待下载完成，自动导出TXT文件
