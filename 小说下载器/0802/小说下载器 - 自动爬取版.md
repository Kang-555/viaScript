# 小说下载器 - 自动爬取版

## 核心逻辑

### 一、获取标题逻辑（四级优先级）

```
getCurrentTitle(doc)
├── 1. extractArticleTitle()     ← 优先：正文区域内的标题元素
├── 2. parsePageTitle()          ← 其次：网页<title>标签拆分
├── 3. extractTitleFromContent() ← 再次：正文内容正则匹配
├── 4. titleSelectors            ← 最后：CSS选择器兜底
└── 5. 默认"未知章节"
```

#### 1. extractArticleTitle() - 提取正文区域内标题

**目标HTML结构**：
```html
<article id="chapterContent">
    <section>
        <h3>第1章 苏婉清·慈母的注视</h3>  ← 章节标题
        <div class="content_txt">
            <p>正文内容...</p>
        </div>
    </section>
</article>
```

**逻辑**：
1. 查找 `article`, `.content_txt`, `#chapterContent` 元素
2. 在其中查找 `h3`, `h2`, `h1` 标题
3. 用正则验证是否符合"第X章"格式：`/^第[零一二三四五六七八九十百千万\d]+[章节卷回部集篇幕]/`
4. 符合则返回，否则返回 null

#### 2. parsePageTitle() - 拆分网页标题

**支持格式**：
- `第X章 章节名_小说名-xx`
- `第X章 章节名_小说名`
- `第X章 章节名`

**正则模式**：
```javascript
/^(第[零一二三四五六七八九十百千万\d]+[章节卷回部集篇幕][^_\-|]+)[_|\-](.+?)[_|\-].+$/  // 第X章 章节名_小说名-xx
/^(第[零一二三四五六七八九十百千万\d]+[章节卷回部集篇幕][^_\-|]+)[_|\-](.+)$/          // 第X章 章节名_小说名
/^(第[零一二三四五六七八九十百千万\d]+[章节卷回部集篇幕].+)$/                          // 仅章节名
```

**返回**：`{ chapterTitle: "第X章 章节名", novelName: "小说名" }`

#### 3. extractTitleFromContent() - 正文正则匹配

**逻辑**：
1. 将正文内容按 `\n` 分割成行
2. 取前5行非空行
3. 用3个正则模式依次匹配：
   - `第X章 XXX`（完整行匹配）
   - `第X章`（开头匹配）
   - `卷X/第X章`（支持卷标题）
4. 匹配成功后，提取到句号/感叹号/问号前的完整标题
5. 跳过超过80字符的行（避免误匹配）

### 二、获取正文逻辑

```
getCurrentContent(doc)
├── 遍历 contentSelectors 查找正文容器
└── extractContent(container)
    ├── 克隆容器节点
    ├── 移除 script, style, noscript, iframe, 广告元素
    ├── 优先提取所有 <p> 标签文本
    └── 否则提取纯文本
```

**contentSelectors 优先级**：
```javascript
[
    'article#chapterContent',
    '#content',
    '.content',
    '.article',
    '.read-content',
    '.chapter-content',
    '.content_txt',
]
```

**extractContent() 逻辑**：
1. 克隆容器节点（避免修改原DOM）
2. 移除干扰元素：`script, style, noscript, iframe, .ad, .ads, .advertisement`
3. 如果有 `<p>` 标签：提取所有 `<p>` 文本，用 `\n\n` 连接
4. 否则：直接提取纯文本

### 三、章节列表

#### 面板结构
```
┌─────────────────────────────────────────────┐
│  自动爬取器                             ×   │
├─────────────────────────────────────────────┤
│  状态: 就绪                                 │
│  已爬取: X 章                               │
│  最新标题: 第1章 XXX                        │
│  最新URL: https://...                       │
├─────────────────────────────────────────────┤
│  [开始]              [停止]                 │
├─────────────────────────────────────────────┤
│  ☑ 全选    [从: __] - [到: __] [选中]       │
│  ┌───────────────────────────────────────┐  │
│  │ ☐ 第1章 苏婉清·慈母的注视             │  │
│  │ ☐ 第2章 XXX                           │  │
│  │ ☐ 第3章 XXX                           │  │
│  └───────────────────────────────────────┘  │
├─────────────────────────────────────────────┤
│  [导出全部]          [导出选中]             │
│  [清空]                                     │
└─────────────────────────────────────────────┘
```

#### 功能说明

| 功能 | 说明 |
|------|------|
| 全选/取消 | 一键选中或取消所有章节 |
| 范围选择 | 输入起始和结束章节号，点击"选中"自动选中范围 |
| 导出全部 | 导出所有章节为TXT文件 |
| 导出选中 | 仅导出选中的章节 |
| 清空 | 清空所有爬取数据 |

#### 范围选择逻辑

```javascript
selectRange()
├── 获取起始和结束章节号（用户输入从1开始）
├── 转换为内部索引（从0开始）
├── 验证范围有效性
├── 清空当前选中状态
├── 选中指定范围内的所有章节
└── 更新章节列表UI
```

#### 导出逻辑

```javascript
exportAll() / exportSelected()
├── 获取小说名（优先级）：
│   ├── 1. config.novelName（爬取时提取）
│   ├── 2. parsePageTitle(document.title) 从网页标题拆分
│   └── 3. 从第一章标题去除章节号
├── 按时间戳排序章节
├── 生成TXT内容
└── 下载文件（文件名：小说名.txt）
```

## 配置项

| 配置 | 默认值 | 说明 |
|------|--------|------|
| delay | 1500 | 爬取间隔（毫秒） |
| minContentLength | 100 | 最小正文长度 |
| contentSelectors | 数组 | 正文容器选择器 |
| titleSelectors | 数组 | 标题元素选择器 |
| nextBtnSelectors | 数组 | 下一章按钮选择器 |
