# 链接净化脚本说明

> 对应文件：`链接新标签打开.user.js` v2.1
> 适用范围：所有网站（`@match *://*/*`）
> 运行时机：`document-start`（DOM 构建前即介入）

---

## 一、核心功能

| 功能 | 说明 |
|---|---|
| 🔗 链接新标签打开 | 强制所有 `<a>` 链接 `target="_blank"`，避免覆盖当前页 |
| 🚀 去中转直达 | 解析知乎/掘金/CSDN/简书/豆瓣/微信/百度/搜狗等中转链接，提取真实地址 |
| 🧹 去追踪参数 | 清理 UTM、fbclid、gclid、spm、scm 等统计与广告追踪参数 |
| 🚫 广告屏蔽 | CSS 隐藏广告元素 + JS 拦截弹窗广告 + 视频播放器区域广告拦截 |
| 🛡️ 安全加固 | 自动添加 `rel="noopener noreferrer"`，防止新标签页篡改原页面 |

---

## 二、中转链接规则库

按优先级从具体到通用匹配，命中第一条即停止。

| 平台 | 匹配规则 | 示例 |
|---|---|---|
| 知乎 | `link.zhihu.com/?target=xxx` | 提取 target 参数 |
| 掘金 | `link.juejin.cn/?target=xxx` | 同上 |
| CSDN | `link.csdn.net/?target=xxx` | 同上 |
| 简书 | `links.jianshu.com/go?target=xxx` | 同上 |
| 豆瓣 | `www.douban.com/link2/?url=xxx` | 提取 url 参数 |
| 微信公众号 | `mp.weixin.qq.com/...&url=xxx` | 同上 |
| 百度搜索 | `www.baidu.com/link?url=xxx` | 同上 |
| 搜狗搜索 | `*.sogou.com/...&url=xxx` | 同上 |
| 通用 url 参数 | `?url=https://...` | 验证为完整 URL 才提取 |
| 通用 target 参数 | `?target=https://...` | 同上 |
| 通用跳转参数 | `?jump/redirect/to/goto/link=https://...` | 同上 |
| /pop 广告中转 | `/pop?url=https://...` | 视频站常见广告跳转 |

## 四、广告屏蔽策略

### 1. CSS 静态隐藏
精准选择器，避免误杀正常内容：
- 类名/ID 含 `ad-container` `ad-wrapper` `ad-banner` `ads-box` `advertisement`
- 常见广告组件：`.ad-popup` `.sidebar-ad` `.float-ad` `.modal-ad`
- 广告 iframe：`iframe[src*="doubleclick"]` `iframe[src*="googlesyndication"]` `ins.adsbygoogle`
- 标记元素：`[data-ad-slot]` `[data-ad-client]` `[aria-label="广告"]`
- 平台广告：`[class*="baidu-union"]` `[class*="google-ads"]` `[class*="tencent-ad"]`
- 悬浮弹窗（双条件）：`[class*="float-ad"][class*="fixed"]`

### 2. 弹窗广告拦截（JS 层）
- **window.open 拦截**：检测小窗口特征（`toolbar=no`+`menubar=no`+尺寸）、广告域名关键词、空 URL
- **点击触发拦截**：检测元素 `onclick` 含 `window.open/alert/showModal` + 广告关键词
- **定时弹窗拦截**：重写 `setTimeout`/`setInterval`，检测字符串/函数体含弹窗+广告特征

### 3. 视频播放器区域广告
点击事件捕获阶段检测：
- 命中 `video, .video-player, .player, #player` 等容器
- 链接含 `/pop?url=` → 阻止默认行为
- 链接含 `ad/popup/modal/promo/offer/coupon` → 阻止默认行为

## 五、链接处理流程

```
processLink(a)
  ├─ 跳过已处理（dataset.linkProcessed）
  ├─ 跳过特殊链接（锚点/javascript:/mailto:/tel:/同页hash）
  ├─ 取绝对 URL（a.href）
  ├─ cleanLinkUrl(url)
  │    ├─ 遍历 redirectRules 提取真实地址
  │    └─ URL 对象清理追踪参数
  ├─ 若有变化 → 替换 a.href
  ├─ a.target = '_blank'
  ├─ a.rel = 'noopener noreferrer'
  └─ 标记 dataset.linkProcessed
```

## 六、执行策略

| 时机 | 动作 | 目的 |
|---|---|---|
| 脚本注入即执行 | `processLinks` + `interceptDynamicLinks` + `blockPopupAds` | DOM 已可用时立即处理 |
| `DOMContentLoaded` | 同上 + `setupEventDelegation` | DOM 完整后补漏 + 注册事件委托 |
| `load` | `processLinks` | 页面完全加载后兜底 |
| `MutationObserver` | 防抖 300ms 触发 `processLinks` | 应对 SPA 动态内容 |

### 事件委托
- 在 `document` 捕获阶段监听 `click`
- 点击时即时处理未标记的链接，优先于页面自身事件
- 特殊处理视频播放器区域内的广告链接

---

## 七、动态跳转拦截

### window.open 重写
- 清洗 URL（去中转 + 去追踪）
- 自动追加 `noopener,noreferrer` 安全参数
- 检测广告弹窗特征并阻止

### 表单处理
- 所有 `target="_self"` 或无 target 的表单改为 `_blank`

---

## 八、性能优化

| 优化点 | 实现 |
|---|---|
| 处理标记 | `dataset.linkProcessed` 避免重复处理同一链接 |
| 防抖 | MutationObserver 回调防抖 300ms |
| 事件委托 | 点击时才处理，比全量扫描省 CPU |
| 精准选择器 | CSS 用具体类名组合，不用通配符 |
| 捕获阶段 | 事件注册在 `capture: true`，优先页面逻辑 |

---

## 九、跳过处理的链接类型

- 锚点 `#xxx`
- `javascript:` 伪协议
- `mailto:` `tel:` 协议
- 同页 hash 变化（origin+pathname+search 相同）
- `about:blank`
- 已标记 `data-link-processed` 的链接

## 十、扩展新规则

### 添加中转平台
在 `redirectRules` 数组头部插入：
```js
{ reg: /^https?:\/\/link\.example\.com\/\?to=(https?[^&]+)/, get: m => decodeURIComponent(m[1]) }
```

### 添加追踪参数
在 `trackParams` 数组追加：
```js
"new_param_name"
```

### 添加广告选择器
在 `GM_addStyle` 中追加：
```css
.new-ad-class { display:none !important; }
```
