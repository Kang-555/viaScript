# 图片下载器-简单版

## 简介

通用型图片批量下载工具，适用于任何网页。通过**手动懒加载**后扫描页面上已显示的图片元素，提取符合条件的图片地址并打包下载。

## 核心特点

- **手动懒加载依赖**：必须先滚动页面让图片全部加载完成，才能扫描到
- **通用性强**：适用于任何网站的图片合集页面
- **操作简单**：扫描 → 打包，两步完成
- **轻量精简**：界面小巧，功能聚焦

## 适用场景

- 网页图片已经通过懒加载显示在页面上
- 需要下载当前可见区域的图片合集
- 图片地址直接暴露在 `src` 或 `data-src` 等属性中
- 不确定图片URL规律，只能被动扫描已加载内容

## 使用方法

### 1. 等待图片加载（关键步骤）

⚠️ **这是最重要的一步！**

- 浏览网页，**手动滚动页面**让需要下载的图片**全部加载完成**
- 确保目标图片已经显示在页面上（不是占位图或 loading 状态）
- 如果图片使用了懒加载，必须滚动到图片位置触发加载

### 2. 点击「扫描」

- 脚本自动收集页面上所有符合条件的图片
- 过滤条件：宽度≥1100 或 高度≥200 的图片（过滤小图标）
- 支持从 `src`、`data-src`、`data-original`、`data-lazy` 等属性提取
- 同时会收集背景图片（`background-image`）
- 扫描完成后显示图片数量（如 "15张"）

### 3. 点击「打包」

- 脚本并发下载所有图片（最多6个同时下载）
- 每个图片下载超时时间为6秒
- 自动生成 ZIP 文件并保存到本地
- 文件名使用网页标题（自动过滤非法字符）
- 打包完成后显示 "完成X张"

## 界面说明

```
┌─────────────┐
│    扫描     │  ← 第一步：图片加载完成后点击
├─────────────┤
│    15张     │  ← 显示扫描到的图片数量
├─────────────┤
│    打包     │  ← 第二步：开始下载并打包
└─────────────┘
```

## 注意事项

| 问题 | 解决方案 |
|------|----------|
| 扫描结果为0张 | 先滚动页面让图片加载完成，再点击扫描 |
| 打包提示"无有效图" | 图片下载失败，可能是网络问题或图片有防盗链 |
| 下载的图片不完整 | 部分图片加载超时，可尝试重新打包 |
| 某些网站图片扫描不到 | 该网站可能使用特殊的图片加载方式，尝试「元素匹配版」 |

## 技术细节

- **图片过滤**：最小宽度 1100px 或最小高度 200px
- **并发限制**：最多6个同时下载
- **超时时间**：6秒
- **支持格式**：jpg、jpeg、png、gif、webp
- **特殊适配**：588ku.com、ibaotu.com、doc88.com、docin.com

## 与「元素匹配版」的区别

| 对比项 | 简单版 | 元素匹配版 |
|--------|--------|-----------|
| 工作原理 | 扫描已加载的图片元素 | 提取模板URL，拼接生成地址 |
| 懒加载要求 | ⚠️ 必须手动滚动加载所有图片 | ✅ 无需等待懒加载 |
| 适用网站 | 通用，任何网站 | 漫画站点（需固定URL规则） |
| 操作步骤 | 2步（扫描→打包） | 4步（解析作品号→解析模板→输入页数→打包） |
| 智能程度 | 简单直接 | 智能提取，自动拼接 |
| 推荐场景 | 单页图片合集、已加载完成的页面 | 多页漫画、分页加载的站点 |
