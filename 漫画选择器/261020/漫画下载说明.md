# 漫画下载流水线 · 脚本说明

两个脚本配合实现「PC 浏览器扫描 → 导出链接清单 → Termux 下载打包」的完整流程。

---

## 脚本列表

| 脚本 | 运行环境 | 职责 |
|---|---|---|
| `图片链接收集器.user.js` | PC 浏览器（Tampermonkey） | 扫描网页图片，导出 `ManHuaUrls.txt` |
| `漫画下载.sh` | Android Termux | 读取 txt，aria2/curl 下载，压缩打包 ZIP |

---

## 数据流总览

```
┌──────────────────────────────────────────────┐
│  PC 浏览器                                     │
│                                                │
│  打开漫画站 ──→ 脚本注入面板 ──→ 点 [扫描]       │
│                                                │
│  1. 自动滚到底部，触发懒加载图片                │
│  2. 等待所有 <img> 加载完成                     │
│  3. 提取 src/srcset/data-src 等属性             │
│  4. 过滤 gif/bmp、过滤小于 400×300 的小图       │
│  5. 去重 + 站点规则修正缩略图 → 原图            │
│  6. 点 [导出txt] → 生成 ManHuaUrls.txt          │
└───────────────────────┬──────────────────────┘
                        │ 文件传到手机
                        │ 微信/网盘/数据线
                        ▼
┌──────────────────────────────────────────────┐
│  Android Termux                                │
│                                                │
│  bash 漫画下载.sh                               │
│                                                │
│  1. 监控 ~/storage/downloads/ManHuaUrls.txt    │
│  2. 首行 #漫画名 → 提取做目录名                 │
│  3. aria2c 6 路并发下载（无则退 curl 单线程）    │
│  4. imagemagick 压缩 JPG 到 quality=80          │
│  5. 打包成 ZIP                                  │
│  6. 删除 txt，循环等下一个任务                  │
└──────────────────────────────────────────────┘
```

## 中间文件格式：`ManHuaUrls.txt`

```
#漫画名 第N话
https://img5.qy0.ru/data/3798/63/0001.jpg?verify=xxx
https://img5.qy0.ru/data/3798/63/0002.jpg?verify=xxx
https://img5.qy0.ru/data/3798/63/0003.jpg?verify=xxx
...
```

- **固定文件名**：始终 `ManHuaUrls.txt`，通过首行 `#漫画名` 传递上下文
- **首行规则**：以 `#` 开头，内容是漫画名/章节名，作为 Termux 端的下载目录名
- **后续行**：纯图片 URL，每行一条，可有空行
- **无 `#` 首行时**：Termux 端自动回退到 `manga_时间戳` 命名

## 脚本一：图片链接收集器.user.js

### 功能面板

```
┌──────────┐
│   链    │  ← 折叠/展开按钮
├──────────┤
│ [ 扫描 ] │  ← 核心按钮：滚动+加载+解析+过滤
│ 12 条   │  ← 实时状态（加载中/解析中/X 条）
│ [导出txt]│  ← 下载 ManHuaUrls.txt
│ [复制全部]│  ← 复制到剪贴板 + 控制台输出
│ [ 清空 ] │  ← 重置列表
└──────────┘
```

### 扫描流程详解

```
scanImages()
│
├─ autoScrollLoad()        自动滚动
│  ├─ window.scrollTo(0, body.scrollHeight)
│  ├─ 等 400ms 让浏览器触发懒加载
│  ├─ 检查 scrollHeight 是否变化
│  │   ├─ 变了 → 还有新图插入，继续滚
│  │   └─ 没变 → sameHits++，连续 3 次 → 停
│  ├─ 15 秒超时兜底
│  └─ 滚回顶部（避免页面停在底部）
│
├─ waitImgLoad() × N       等待所有 <img> 加载
│  ├─ img.complete && naturalWidth > 0 → 立即成功
│  ├─ 否则监听 load/error 事件
│  └─ 6 秒超时（懒加载图拿不到也不阻塞）
│
├─ resolveImgSrc()          取真实图片地址
│  ├─ img.currentSrc         （包含 srcset 选中的源）
│  ├─ img.src
│  ├─ img.srcset 最后一项
│  └─ 懒加载属性 fallback:
│      data-src / data-original / data-lazy
│      data-url / data-lazy-src / data-original-src
│      data-raw / data-img / data-image / data-srcset
│
├─ 过滤
│  ├─ 排除 data:/blob: 内联图
│  ├─ 排除 gif / bmp（漫画正文不会用）
│  └─ 排除宽 < 400 或 高 < 300 的小图（缩略图/按钮）
│
├─ 修正
│  ├─ new URL(src, location.href).href  转绝对路径
│  ├─ ruleMap 站点规则修正
│  │   ├─ 588ku.com / ibaotu.com → 去掉 !xxx 裁剪参数
│  │   └─ doc88.com / docin.com → _thumb.jpg → .jpg
│  └─ 追加 getBgImgs() 的 CSS 背景图（同样过滤 gif）
│
└─ imgList = [...new Set(temp)]   去重
```

### 控制台输出

扫描完成后 F12 → Console 可见分组输出，方便人工核对：

```
[链接收集器] 扫描完成，共 15 条链接
  ▼ [链接收集器] 完整链接列表
      1. https://img5.qy0.ru/data/3798/63/0001.jpg?verify=xxx
      2. https://img5.qy0.ru/data/3798/63/0002.jpg?verify=xxx
      ...
```

### 可调参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `MIN_W` | 400 | 图片最小宽度，低于此值过滤 |
| `MIN_H` | 300 | 图片最小高度，低于此值过滤 |
| `EXT_BLACKLIST` | `gif\|bmp` | 排除的扩展名 |
| `waitImgLoad` timeout | 6000ms | 单张图片等待超时 |
| `autoScrollLoad` MAX_WAIT | 15000ms | 滚动总超时 |

## 脚本二：漫画下载.sh

### 运行方式

```bash
# Termux 里
pkg install aria2 imagemagick zip wget   # 可选依赖
bash 漫画下载.sh
```

### 处理流程详解

```
主循环 while true
│
├─ 匹配 ManHuaUrls.txt（ls -1tr 取最新）
│  ├─ 无文件 → echo "✅无任务队列，退出" → break
│  └─ 有文件 → 处理
│
├─ 解析首行
│  ├─ ^#(.+)$ 匹配成功
│  │   TASK_NAME = 漫画名        （用于目录/ZIP命名）
│  │   DOWNLOAD_LIST = grep -ve '^\s*#' 去掉注释行
│  └─ 没 # 注释
│      TASK_NAME = manga_YYYYMMDD_HHMMSS
│      DOWNLOAD_LIST = cat 全文件
│
├─ TASK_NAME 安全化
│   sed 's/[\\/:*?"<>|]/_/g'    替换非法字符
│   head -c 80                   截 80 字符防路径过长
│
├─ 下载
│  ├─ aria2c 存在 → 6 路并发
│  │   aria2c -i .urls -x 6 -s 6 -k 1M -c
│  │     --user-agent="Mozilla/5.0"
│  │     --allow-overwrite=false
│  │     --save-session=fail.txt   失败链接自动记录
│  │
│  └─ aria2c 不存在 → curl 循环
│      curl -s -O -C - --retry 3
│        -C -      断点续传
│        -f "$fn"  跳过已存在
│        失败时 echo "$u" >> fail.txt
│
├─ JPG 压缩（可选）
│  ├─ mogrify 存在 → find . -type f \( -iname "*.jpg" ... \) | xargs mogrify -quality 80
│  └─ 不存在 → 跳过
│
├─ 打包 ZIP
│   zip -r ~/storage/downloads/manga_downloads/漫画名.zip 漫画名/
│
└─ 清理
   ├─ rm -f ManHuaUrls.txt   删除任务文件
   └─ while true 继续等下一个
```

### 下载目录结构

```
~/storage/downloads/
├── ManHuaUrls.txt               ← 待处理（脚本启动时存在就处理完删）
└── manga_downloads/
    ├── 进击的巨人_第1话.zip     ← 打包后的 ZIP
    ├── 进击的巨人_第1话/        ← 原图文件夹（打包后可删）
    │   ├── 0001.jpg
    │   ├── 0002.jpg
    │   └── fail.txt             ← 下载失败的链接
    └── manga_20261020_143022/   ← 无漫画名时的兜底命名
```

### 依赖关系

| 依赖 | 必需 | 说明 |
|---|---|---|
| `bash` | 是 | Termux 自带 |
| `aria2c` | 否（推荐） | 并发下载，速度快 |
| `curl` | 否（aria2c 不存在时自动用） | Termux 自带 |
| `imagemagick` | 否 | mogrify 压缩 JPG，省空间 |
| `zip` | 否 | 打包；无则脚本只下载不压缩 |

### 可选修改

| 行 | 当前 | 改什么 |
|---|---|---|
| `PATTERN` | `ManHuaUrls.txt` | 改成其他文件名即可并行多任务 |
| aria2c `-x 6 -s 6` | 6 路 | 手机带宽小可改 4，想更快改 8 |
| `TASK_NAME` 截 80 | head -c 80 | 想更长改大值 |
| `rm -rf "$MANGA_DIR"` | 已注释 | 取消注释则打包后删原图，省空间 |

## 快速上手

```
1. PC 浏览器打开漫画站，Tampermonkey 已启用脚本
2. 点面板 [扫描] → 等滚动和加载完成 → 控制台核对链接
3. 点 [导出txt] → 浏览器下载 ManHuaUrls.txt
4. 把 ManHuaUrls.txt 传到手机 ~/storage/downloads/
5. Termux: bash 漫画下载.sh
6. 等它下完、压缩、打包、清理，自动退出
7. ~/storage/downloads/manga_downloads/ 下拿 ZIP
```

## 常见问题

**Q: wnacg 之类站点 verify 签名过期怎么办？**
A: 扫完尽快传手机下载，一般几小时内有效。过期的 aria2c 会记录到 fail.txt。

**Q: 扫描出来链接很多有重复？**
A: 脚本已用 `new Set()` 去重，不用担心。

**Q: 扫描完 Termux 没文件怎么办？**
A: 脚本会直接退出，`echo "✅无任务队列，退出"` 表示没匹配到 `ManHuaUrls.txt`。确认文件名完全一致。

**Q: 想重新下失败的？**
A: 手动 `bash 漫画下载.sh` 前，把 fail.txt 内容移到新的 ManHuaUrls.txt，脚本不删除已存在文件（curl 有 -C - 断点续传，aria2c 有 --allow-overwrite=false）。
