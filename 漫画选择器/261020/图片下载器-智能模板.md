# 图片下载器-智能模板

## 简介

智能模板分析型图片批量下载工具。通过**自动收集样本、分析URL规律、验证后批量下载**的方式，自适应各种图片命名格式，无需手动解析模板。

## 核心特点

- **自动分析规律**：收集4个样本URL，自动对比分析出页码位置、位数、后缀、扩展名
- **智能验证**：分析出规律后，自动下载6个验证（必须全部成功），通过后才批量下载
- **自适应格式**：支持 `01.jpg`、`01_1.png`、`001_2.webp` 等各种命名格式
- **无需硬编码**：不依赖固定正则，通过字符串对比找出变化规律

## 适用场景

- 图片URL有规律但格式不确定（可能有 `_1`、`_2` 等后缀）
- 不想手动分析模板，希望自动识别
- 不同网站命名规则不同，需要自适应
- 页面有多个图片，可以提取样本分析

## 使用方法

### 步骤1：分析并验证模板

点击「分析模板」按钮，脚本会：

1. **收集样本**：在页面 `div#content` 或 `body` 中查找前4张图片
2. **分析规律**：对比4个URL的差异，自动识别：
   - **前缀**：URL固定部分（如 `https://xxx.com/data/1234/56/`）
   - **页码位数**：如 `01` 是2位，`001` 是3位
   - **后缀**：如 `_1`、`_2`（可能没有）
   - **扩展名**：如 `png`、`jpg`
3. **自动验证**：用分析出的规律生成6个URL并尝试下载（只试1次，8秒超时）

**判断结果**：
- ✅ **6个全部成功**：验证通过，显示输入框
- ❌ **有失败**：验证失败，提示重新分析

分析成功后显示规律，如：
```
规律: https://xxx.com/data/1234/56/{页码}_1.png
```

验证通过后会显示：
```
验证通过(6/6)
```

**失败处理**：
- 如果页面图片少于2个，提示"样本不足"
- 如果URL差异无法识别，提示"无法分析规律"
- 如果验证有失败，提示"验证失败(X/6)，请重新分析"

### 步骤3：输入页数并打包

1. **输入总页数**：在输入框填写要下载的总页数
2. **点击「打包下载」**：
   - 按规律生成所有URL
   - 并发下载（最多6个同时）
   - 失败自动补漏
   - 生成ZIP文件

## 分析规律示例

| 样本URL | 分析结果 |
|---------|----------|
| `.../01.jpg` | 页码2位，无后缀，jpg |
| `.../01_1.png` | 页码2位，后缀`_1`，png |
| `.../001_2.webp` | 页码3位，后缀`_2`，webp |
| `.../0001.jpg` | 页码4位，无后缀，jpg |

## 注意事项

| 问题 | 解决方案 |
|------|----------|
| 样本不足 | 确保页面已加载，且 `div#content` 或 `body` 中有图片 |
| 无法分析规律 | 4个样本URL差异太大，可能不在同一序列 |
| 验证失败 | 分析的规律不正确，可能是后缀识别错误，点击「分析模板」重新分析 |
| 下载大量失败 | 网站有防盗链或频率限制，减少并发或分批下载 |

## 技术细节

- **样本数量**：4个（可配置 `SAMPLE_COUNT`）
- **验证数量**：6个（可配置 `VERIFY_COUNT`）
- **验证通过阈值**：必须全部成功（6/6）
- **并发限制**：6个同时下载
- **超时时间**：验证8秒，正式下载15秒
- **重试次数**：正式下载3次

## 适用网站特征

本脚本最适合：

1. **图片URL有规律**：页码按顺序排列
2. **可能有后缀**：如 `_1`、`_2` 等
3. **页面有样本图**：至少2张以上的图片可供分析
4. **格式不确定**：不想手动分析模板，希望自动识别
