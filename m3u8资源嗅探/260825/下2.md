## 📋 脚本功能说明

### 基本信息
| 项目 | 内容 |
|------|------|
| **脚本名称** | m3u8下2 |
| **版本** | 2.0 |
| **功能描述** | 网页 m3u8 视频资源嗅探与下载，支持 m3u8 分片直接拼接为 TS 文件、AES-128 解密，适配 Via/Kiwi 手机浏览器 |
| **运行环境** | Tampermonkey（油猴） |
| **匹配范围** | 所有网页 (`*://*/*`) |

---

### 核心功能

#### 1. **网络嗅探**
- 自动监听网页中的 `fetch` 和 `XHR` 请求
- 定时扫描 `performance` 资源列表
- 自动识别 **m3u8**、**MP4**、**MOV** 三种视频格式
- 去重机制：同一 URL 不会重复提示
- 支持暂停/恢复嗅探

#### 2. **m3u8 解析**
- 自动解析主 m3u8 多码率文件，智能选择最高码率流
- 解析分片列表、时长、加密状态
- 支持 `#EXT-X-KEY` AES-128 加密识别
- 支持 `#EXT-X-MEDIA-SEQUENCE` 序列号
- 后台自动预解析资源信息（时长、分片数、加密状态）

#### 3. **下载功能**
- **m3u8 下载**：多线程（4线程）并发下载分片，自动拼接为 `.ts` 文件
- **MP4 下载**：直接下载，手机端支持调用浏览器原生下载器
- **AES-128 解密**：使用 Web Crypto API 自动解密加密分片
- **断点重试**：最多重试 3 次，指数退避延迟
- **下载范围选择**：
  - **时间模式**：按起止时间（HHMMSS 格式）截取下载
  - **分片模式**：按起始/结束分片序号下载

#### 4. **进度监控**
- 实时显示下载进度（已完成/总分片数）
- 实时下载速度显示
- 预计剩余时间（ETA）
- 失败分片统计

## 🖥️ UI 交互说明

### 面板一：嗅探主面板

**触发方式**：脚本加载后自动在页面左下角显示悬浮面板

**交互流程**：
1. 脚本自动运行，页面左下角出现「视频嗅探」面板
2. 当页面加载视频资源时，自动添加到资源列表
3. 每个资源显示：类型标签、文件名、时长、分片数、加密状态
4. 点击 **「复制」** 按钮 → 复制视频 URL 到剪贴板
5. 点击 **「选择」** 按钮 → 进入下载面板
6. 点击 **「停止嗅探/继续嗅探」** → 切换嗅探状态
7. 底部状态栏显示资源总数和嗅探状态

---

### 面板二：下载面板

**触发方式**：点击资源列表中的「选择」按钮进入

**交互流程**：
1. 顶部显示可编辑的文件名（点击文件名可修改）
2. 显示资源信息：时长、分片数、加密状态
3. **下载范围设置**（仅 m3u8 资源）：
   - **时间模式**：输入起止时间（如 `000530` 表示 00分05秒30 → 实际是 `00:00:05` 到 `00:05:30` 的时分秒格式 `HHMMSS`）
   - **分片模式**：输入起始/结束分片序号
   - 两种模式通过单选按钮切换，切换时自动启用/禁用对应输入框
4. 点击 **「下载」** 按钮 → 开始下载
5. 下载过程中显示实时进度、速度、ETA
6. 点击 **「清空」** 按钮 → 取消当前下载并重置状态
7. 点击 **「返回列表」** → 返回嗅探主面板

## 🎨 UI 外观描述

### 整体样式
- **位置**：页面左下角（`bottom: 10px, left: 10px`）
- **宽度**：最大 320px，自适应屏幕（`min(320px, calc(100vw - 20px))`）
- **最大高度**：200px
- **背景**：半透明黑色 `rgba(0, 0, 0, 0.85)` + 毛玻璃模糊效果
- **边框**：主题色（主窗口绿色 `#4caf50`，iframe 粉色 `#e91e63`）
- **圆角**：6px
- **字体**：无衬线字体，11px 字号

### 头部栏
- 背景：`rgba(255,255,255,0.08)` 半透明白色
- 标题：主题色加粗文字（「视频嗅探」或「下载：文件名」）
- 右侧按钮：透明背景 + 主题色边框的小按钮

### 资源列表项
- 每项之间用半透明分割线分隔
- **类型标签**：
  - m3u8 → 绿色背景 `#4caf50` + 黑色文字
  - MP4 → 蓝色背景 `#2196F3` + 白色文字
- **文件名**：加粗白色文字
- **信息行**：灰色小字，显示 `时长 | 分片数 | 加密状态`
- **操作按钮**：
  - 「复制」→ 灰色背景
  - 「选择」→ 主题色背景

### 下载面板
- **文件名编辑**：点击后变为输入框，蓝色背景 `#0f3460`
- **模式切换行**：单选按钮 + 标签 + 输入框，禁用状态变灰
- **下载按钮**：主题色背景 + 黑色文字，下载中变灰禁用
- **清空按钮**：红色背景 `#f44336`
- **进度信息**：灰色小字，显示 `X/Y分片 | 大小 | 速度 | ETA`

### 空状态提示
- 居中显示「等待嗅探视频资源...」灰色文字

## 📊 技术架构

| 模块 | 说明 |
|------|------|
| `Config` | 全局配置（线程数、重试次数、颜色主题等） |
| `Utils` | 工具函数库（格式化、请求、DOM创建、剪贴板等） |
| `AESCrypto` | AES-128 解密模块（Web Crypto API） |
| `Bus` | 事件总线（发布/订阅模式） |
| `Sniffer` | 网络嗅探器（Hook Fetch/XHR/Performance） |
| `VideoWriter` | 视频写入器（分片拼接为 Blob） |
| `UI` | 悬浮面板（Shadow DOM 隔离样式） |
