# 面板UI优化方案

## 一、核心问题

1. **嗅探无法聚焦**：选择目标视频后，嗅探器继续嗅探所有视频资源，列表不断增加无关资源
2. **视频信息缺失**：只显示文件名和URL，缺少时长、分片数、大小等关键信息
3. **交互不够直观**：展开/收起操作单一，缺少快捷操作和状态反馈

---

## 二、设计原则

1. **靠左下角**：不影响上方视频播放
2. **高度尽量小**：紧凑布局，节省空间
3. **不要图标**：纯文字按钮
4. **两个独立UI面板**：
   - 面板1：嗅探列表（选择目标）
   - 面板2：下载页面（设置范围+下载）

## 四、交互逻辑

### 1. 嗅探列表面板

**显示时机**：
- 页面加载后自动显示
- 嗅探到视频资源后添加到列表

**操作按钮**：
- **复制**：复制视频URL到剪贴板
- **选择**：关闭面板1，打开面板2，传入选中的视频信息
- **停止嗅探**：停止继续嗅探新资源，列表保持不变
- **继续嗅探**：恢复嗅探功能

**信息展示**：
- 类型标签：M3U8 / MP4
- 文件名
- 时长（m3u8解析后显示）
- 分片数（m3u8）
- 加密状态：AES / 未加密
- 预估大小

---

### 2. 下载页面面板

**打开时机**：
- 点击嗅探列表的"选择"按钮

**文件名称**：
- 默认显示页面title
- 可点击编辑，点击后变为输入框
- 编辑完成后自动保存

**下载范围设置**：
- **时间模式**：单选按钮选中，输入框支持 `000000` 格式（如 `000000` 表示0时0分0秒，`053200` 表示5时32分0秒）
- **切片模式**：单选按钮选中，输入起止分片索引（如 `0` - `127`）
- 两种模式互斥，通过单选按钮切换
- 留空表示下载全部

**操作按钮**：
- **清空**：
  - 取消当前下载（如有）
  - 清空已下载的分片数据
  - 释放内存
  - 重置进度
  - 下载按钮恢复可点击
- **下载**：
  - 未下载时：开始下载，按钮变为"下载中..."且不可点击
  - 下载中：显示"下载中..."，按钮不可点击
  - 下载完成：变为"重新下载"，按钮可点击
  - 下载失败：变为"重试"，按钮可点击

**下载进度显示**：
- 位置：在按钮下方
- 内容：
  - 下载中：`57/128分片 | 125MB/256MB` + `速度: 2.5MB/s | ETA 00:52`
  - 下载完成：`下载完成 | 256MB | 用时 01:42`
  - 下载失败：`下载失败: 分片#45请求超时`

**返回列表**：
- 关闭面板2，重新打开面板1
- 保留当前下载状态（如下载中则继续）

---

### 3. 状态流转

```
嗅探列表
  ↓ 点击"选择"
下载页面（未下载）
  ↓ 点击"下载"
下载页面（下载中，按钮不可点击）
  ↓ 下载完成
下载页面（下载完成，按钮变为"重新下载"）
  ↓ 点击"重新下载"
下载页面（下载中，按钮不可点击）
  ↓ 点击"清空"
下载页面（未下载，重置状态，按钮可点击）
  ↓ 点击"返回列表"
嗅探列表
```

## 五、技术实现要点

### 1. 面板切换

```javascript
class UI {
  constructor() {
    this.currentPanel = 'sniffer'; // 'sniffer' | 'download'
    this.selectedResource = null;  // 当前选中的资源
    this.downloadState = null;     // 下载状态
    this.snifferPaused = false;    // 嗅探是否暂停
  }
  
  showSnifferPanel() {
    this.currentPanel = 'sniffer';
    this.renderSnifferList();
  }
  
  showDownloadPanel(resource) {
    this.currentPanel = 'download';
    this.selectedResource = resource;
    this.renderDownloadPanel();
  }
  
  toggleSniffer() {
    this.snifferPaused = !this.snifferPaused;
    // 通知Sniffer类暂停/恢复嗅探
  }
}
```

### 2. 下载状态管理

```javascript
const downloadState = {
  resource: null,        // 当前资源
  status: 'idle',        // 'idle' | 'downloading' | 'done' | 'error'
  progress: 0,           // 0-100
  completedSegments: 0,  // 已完成分片数
  totalSegments: 0,      // 总分片数
  downloadedBytes: 0,    // 已下载字节
  totalBytes: 0,         // 总字节
  speed: 0,              // 速度
  eta: 0,                // 预计剩余时间
  error: null,           // 错误信息
  abortController: null  // 用于取消下载
};

function clearDownload() {
  if (downloadState.abortController) {
    downloadState.abortController.abort();
  }
  downloadState = { ...initialState };
  // 清空buffers，释放内存
  writer.buffers = [];
  writer.totalSize = 0;
  // 下载按钮恢复可点击
  downloadBtn.disabled = false;
  downloadBtn.textContent = '下载';
}
```

### 3. 文件名编辑

```javascript
function renderFileName(item, container) {
  const nameSpan = Utils.createElement('span', { 
    class: 'filename',
    onclick: () => startEditName(nameSpan, item)
  }, item.filename || document.title);
  container.appendChild(nameSpan);
}

function startEditName(nameSpan, item) {
  const input = Utils.createElement('input', {
    type: 'text',
    value: nameSpan.textContent,
    onblur: () => finishEditName(input, nameSpan, item),
    onkeydown: (e) => {
      if (e.key === 'Enter') input.blur();
    }
  });
  nameSpan.replaceWith(input);
  input.focus();
  input.select();
}

function finishEditName(input, nameSpan, item) {
  item.filename = input.value || document.title;
  input.replaceWith(nameSpan);
  nameSpan.textContent = item.filename;
}
```

### 4. 时间格式解析

```javascript
// 支持 000000 格式：HHMMSS
const parseTimeInput = (str) => {
  if (!str || str.length !== 6) return 0;
  const h = parseInt(str.substring(0, 2)) || 0;
  const m = parseInt(str.substring(2, 4)) || 0;
  const s = parseInt(str.substring(4, 6)) || 0;
  return h * 3600 + m * 60 + s;
};

// 秒数转 000000 格式
const formatTimeInput = (seconds) => {
  const h = Math.floor(seconds / 3600).toString().padStart(2, '0');
  const m = Math.floor((seconds % 3600) / 60).toString().padStart(2, '0');
  const s = Math.floor(seconds % 60).toString().padStart(2, '0');
  return h + m + s;
};
```

### 5. 内存管理

- 点击"清空"时：
  - 调用 `abortController.abort()` 取消请求
  - 清空 `VideoWriter.buffers` 数组
  - 重置 `totalSize = 0`
  - 触发垃圾回收（可选）

### 6. 重复下载

- 下载完成后，点击"重新下载"：
  - 重置下载状态
  - 清空buffers
  - 使用相同的时间/切片范围重新开始下载

## 七、优先级

1. **P0**：两个面板切换逻辑
2. **P1**：嗅探列表显示（含视频信息）
3. **P2**：下载页面（范围设置+下载）
4. **P3**：下载进度显示
5. **P4**：清空功能（取消下载+释放内存）
6. **P5**：重新下载功能
7. **P6**：文件名可编辑
8. **P7**：停止/继续嗅探功能
