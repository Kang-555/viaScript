# 短视频批量下载工具

通过浏览器油猴脚本嗅探页面中的 m3u8/mp4 视频资源，生成 N_m3u8DL-RE / curl 批量下载命令，再在 Termux 中自动执行下载。

## 文件说明

| 文件 | 作用 |
|------|------|
| `短视频批量下载.user.js` | 油猴脚本，负责嗅探、收集、生成命令 |
| `配套命令.hs` | Termux 脚本，读取 batch*.txt 并逐条执行下载 |

## 使用步骤

### 1. 安装油猴脚本

将 `短视频批量下载.user.js` 安装到 Tampermonkey / Violentmonkey 等脚本管理器。

### 2. 浏览器端 — 嗅探收集

打开目标网页后，左下角自动出现嗅探面板：

- **嗅探收集 Tab**：自动捕获页面中的 m3u8/mp4 请求，也可点击「手动粘贴」添加链接
- 每条记录支持：复制链接、直接下载、单条删除
- 点击「清空列表」重置全部

### 3. 生成批量命令

切换到 **批量生成 Tab**：

- 填写「基础文件名」（默认取页面标题），脚本自动追加 `_1 _2 ...` 序号
- 命令预览区自动生成全部下载命令
- 点击「复制全部」或「导出 batch.txt」

### 4. Termux 端 — 执行下载

将导出的 `batch.txt` 放到 Termux 的 `~/storage/downloads/` 目录下（文件名需匹配 `batch*.txt`），然后运行：

```bash
bash 配套命令.hs
```

脚本逻辑：

1. 扫描 `~/storage/downloads/` 下所有 `batch*.txt` 文件
2. 从第一条命令中自动提取文件夹名（优先取《》书名号内的内容）
3. 创建子文件夹，将该批次所有文件下载到该子目录
4. 下载完成后自动删除已处理的 batch 文件
5. 循环处理队列中所有 batch 文件，全部完成后退出

### 目录名提取规则

| 优先级 | 规则 | 示例 |
|--------|------|------|
| 1 | `--save-name` 参数中《》内的内容 | `--save-name "《课程名》_1"` → `课程名` |
| 2 | `-o` 路径中去除扩展名后截取 | `-o ~/storage/downloads/视频名.mp4` → `视频名` |
| 3 | 去除末尾 `-数字` 后缀 | `课程名-3` → `课程名` |

## 依赖

- **浏览器**：Tampermonkey 或同类脚本管理器
- **Termux**：`curl`（mp4 下载）、[N_m3u8DL-RE](https://github.com/nilaoda/N_m3u8DL-RE)（m3u8 下载，路径 `~/test/N_m3u8DL-RE`）

## 注意事项

- m3u8 命令默认使用 8 线程、5 次重试，可根据网络情况调整脚本参数
- batch 文件处理完会自动删除，如需保留请提前备份
- 嗅探脚本通过 Hook `fetch` / `XMLHttpRequest` / `PerformanceObserver` 捕获资源，对 blob 加密的视频无效
