# 命令生成器.user.js — 逻辑说明

## 用途
Tampermonkey 用户脚本，运行在浏览器端，自动嗅探页面上的 m3u8 / mp4 视频资源，生成 Termux 可执行的下载命令（N_m3u8DL-RE 或 curl），一键导出 txt 到 `/sdcard/Download/`。

## 与 Termux 侧的配合流程

```
┌─ 浏览器端（手机） ─────────────────────────────┐     ┌─ Termux 端 ─────────────────────────┐
│                                                  │     │                                        │
│  用户打开视频页                                   │     │                                        │
│     ↓                                            │     │                                        │
│  userscript 嗅探 m3u8 / mp4                       │     │                                        │
│     ↓                                            │     │                                        │
│  用户在面板选资源 → 确认时间段 → 生成命令           │     │                                        │
│     ↓                                            │     │                                        │
│  点击"下载" → 浏览器保存 /sdcard/Download/标题.txt│────→│  跑 ./c                                │
│                                                  │     │     ↓                                  │
│                                                  │     │  find 捞 .txt                          │
│                                                  │     │     ↓                                  │
│                                                  │     │  bash 执行 txt 内的命令                 │
│                                                  │     │     ↓                                  │
│                                                  │     │  视频落到 /sdcard/Download/videos/      │
│                                                  │     │     ↓                                  │
│                                                  │     │  记录 success.log / fail_xxx.log        │
└──────────────────────────────────────────────────┘     └────────────────────────────────────────┘
```

## 嗅探层：五种捕获方式

脚本同时开了 5 个嗅探通道，任一命中都会调用 `handleVideoFound()` 去重登记：

| 通道 | 原理 | 覆盖场景 |
|------|------|----------|
| XMLHttpRequest hook | 包装 `open()` + 监听 `load` | 页面通过 XHR 主动请求的视频 |
| fetch hook | `window.fetch = async function` | 现代 API 异步加载的视频 |
| PerformanceObserver | 监听 `resource` entryType | 所有已加载的网络资源（兜底） |
| DOM 扫描 + MutationObserver | 查 `<video>` / `<source>` 的 `src` | HTML 直接写死的视频地址、SPA 动态插入 |
| GM_webRequest | Tampermonkey API，拦截所有 m3u8/mp4 URL | 绕过 JS hook 的请求（最强拦截） |

另外还有两个辅助入口：
- `history.pushState/replaceState` hook — SPA 路由切换时重扫
- `window.postMessage` — iframe 资源转发到顶层窗口

### URL 类型判定（`detectType()`）
```
.mp4   → curl 单文件下载
.m3u8  → N_m3u8DL-RE 分段下载+自动合并
```
优先级：URL 后缀 > Content-Type 响应头。

### 去重机制
`handleVideoFound()` 用 `type + '::' + url.split('?')[0]` 作为 key，丢进 `Set`，同一个资源只记一次。

## 命令构造（`buildCommand()`）

### 公共参数
| 参数 | 值 |
|------|----|
| 下载目录 | `/sdcard/Download/videos` |
| UA | Android Chrome 129 |
| Referer | 当前页面 URL |
| 前置 | `mkdir -p /sdcard/Download/videos`（确保目录存在） |

### mp4 命令结构
```bash
mkdir -p /sdcard/Download/videos
curl -L "URL" \
  -H "User-Agent: ..." \
  -H "Referer: ..." \
  --connect-timeout 15 \
  --retry 3 \
  --retry-delay 2 \
  -o /sdcard/Download/videos/标题.mp4
```
- 单文件直下，不需要合并

### m3u8 命令结构
```bash
mkdir -p /sdcard/Download/videos
~/test/N_m3u8DL-RE "URL" \
  -H "User-Agent: ..." \
  -H "Referer: ..." \
  --custom-range "000010-000030"   ← 仅当用户填了时间段
  --thread-count 8 \
  --download-retry-count 5 \
  --log-level off \
  --save-dir /sdcard/Download/videos \
  --save-name "标题"
```
- `--custom-range` 只在 start + end 都填写时才拼入
- N_m3u8DL-RE **自动合并**分片为 mp4，无额外合并命令

## 关键常量

| 常量 | 值 | 说明 |
|------|----|------|
| `VIDEOS_DIR` | `/sdcard/Download/videos` | 视频成品存放目录 |
| N_m3u8DL-RE 路径 | `~/test/N_m3u8DL-RE` | Termux 侧需提前放好 |
| 默认文件名 | `document.title` → `safeName()` | 取页面标题，非法字符替换为 `_` |
| txt 下载文件名 | `safeName(state.fileName) + '.txt'` | 与视频同名 |

## 辅助函数速查

| 函数 | 作用 |
|------|------|
| `safeName(s)` | 替换 `[\\/:*?"<>|]` 为 `_`，防文件名非法字符 |
| `toHMS(str)` | `HHMMSS` 6位数字 → `HH:MM:SS` 时间格式 |
| `copyToClipboard()` | 优先 `navigator.clipboard` → `GM_setClipboard` → execCommand |
| `downloadTxt()` | iOS 用 data URL 打开（无法直接下载），Android 用 Blob + `<a download>` |
| `showToast()` | shadow DOM 内飘字，1.8s 自动消失 |
| `startWatchdog()` | 每 2 秒检查 shadow root 是否还挂着，掉了就重建 |

## 目录约定

```
/sdcard/Download/                 ← shell 脚本扫描 .txt 的地方
├── 视频标题.txt                   ← userscript 下载的命令文件
├── videos/                       ← 视频成品目录（userscript 自动 mkdir）
│   ├── 标题A.mp4                 ← curl 直下的 mp4
│   └── 标题B.mp4                 ← N_m3u8DL-RE 合并后的 m3u8
├── exec_success/                 ← shell 成功日志
│   └── success.log
└── exec_fail/                    ← shell 失败日志
    └── fail_标题C.log
```
