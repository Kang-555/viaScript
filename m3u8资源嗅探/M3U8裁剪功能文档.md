# M3U8裁剪 · 正则生成器

> 版本：1.6 | 适用：Via浏览器 + Tampermonkey + 1DM下载器

## 功能概述

解析M3U8播放列表，通过多时间段筛选分片，自动生成用于1DM下载器的正则表达式，支持裁剪M3U8文件。完整支持 `#EXT-X-DISCONTINUITY` 不连续标记和 `#EXT-X-TARGETDURATION` 标签。

## 使用流程

### 1. 解析M3U8

1. 在输入框粘贴M3U8链接
2. 点击 **解析链接**
3. 等待解析完成

解析完成后显示：
- 总分片数量、总时长、平均分片时长
- `TARGETDURATION` 值
- 是否包含不连续标记
- 是否为fMP4流

### 2. 设置时间段

- 默认时间段：`00:00:00 - 00:01:00`
- **输入方式**：直接敲数字，自动补冒号
  - 输入 `000120` → 自动变为 `00:01:20`
  - 输入 `1234` → 自动变为 `00:12:34`
  - 最多6位数字 `HHmmss`
- **添加时间段**：点击 `➕ 添加`，新段从上一段结束时间开始
- **删除时间段**：点击 `✕`，至少保留一个时间段
- **编辑保护**：添加/删除前自动同步已编辑的值，不会丢失

### 3. 筛选与生成

1. 点击 **预览筛选**：查看筛选后的分片数量和总时长
2. 点击 **生成正则**：自动生成正则表达式

### 4. 使用正则

- **复制正则**：将正则表达式复制到剪贴板，粘贴到1DM下载器的正则过滤框
- **复制匹配URL**：复制所有匹配的分片URL列表

### 5. 裁剪M3U8

- **生成裁剪M3U8**：根据筛选结果生成新的M3U8内容
- **复制裁剪文本**：复制裁剪后的M3U8文本
- **下载clip.m3u8**：下载裁剪后的M3U8文件

## 正则生成规则

### 纯数字分片

分片序号为纯数字时，按时间段分别生成正则，用 `|` 拼接：

```
时间段1: 分片 257471352-257471382
时间段2: 分片 257472161-257472242

生成正则：
(?:2574713(?:5[2-9]|[6-7]\d|8[0-2]))|(?:257472(?:1(?:6[1-9]|[7-8]\d|9[0-9])|2(?:0[0-9]|[1-3]\d|4[0-2])))
```

**算法特点**：
- 递归处理进位，避免 `[6-4]` 等非法字符类
- 按公共前缀分段，生成紧凑正则
- 每个时间段独立生成，互不干扰

### 非数字分片

分片序号包含字母或特殊字符时，用 `|` 连接所有文件名并转义：

```
(?:seg_a|seg_b|seg_c)
```

## 技术细节

### 时间输入处理

| 函数 | 功能 |
|------|------|
| `timeToSec(str)` | `HH:mm:ss` → 秒数 |
| `secToTime(sec)` | 秒数 → `HH:mm:ss` |
| `numToHms(digits)` | 纯数字 → 自动补冒号格式化 |

### 正则生成函数

| 函数 | 功能 |
|------|------|
| `buildNumericRangeRegex(min, max)` | 数字范围→正则，处理跨位数 |
| `buildSameLengthRegex(minStr, maxStr)` | 等长数字范围→正则 |
| `buildSuffixRegex(minS, maxS)` | 递归处理后缀，处理进位 |
| `commonPrefix(a, b)` | 提取公共前缀 |
| `mergeContinuousRanges(nums)` | 合并连续数字为范围 |
| `generateRegexFromSegList(segList, ranges)` | 按时间段分别生成正则再拼接 |

### M3U8解析与输出

| 功能 | 说明 |
|------|------|
| `#EXT-X-DISCONTINUITY` | 解析时标记分片，输出时恢复标签 |
| `#EXT-X-TARGETDURATION` | 解析时提取值，输出时写入头部 |
| `#EXT-X-KEY` | 支持AES-128加密分片 |
| `#EXT-X-MAP` | 支持fMP4流 |

## 注意事项

1. **跨域问题**：链接解析受浏览器同源策略限制，跨域时无法解析
2. **时间段校验**：开始时间必须早于结束时间
3. **正则有效性**：算法确保生成的正则无 `[x-y]` 倒序等非法语法
4. **序号跳号**：正则算法假设时间段内分片序号连续，跳号时可能匹配到不存在的URL
5. **不连续标记**：完整支持 `#EXT-X-DISCONTINUITY`，多拼接流裁剪后播放正常
6. **数字边界**：生成的正则包含数字边界断言 `(?<!\d)` 和 `(?!\d)`，避免 `257472242` 匹配到 `2574722421`
