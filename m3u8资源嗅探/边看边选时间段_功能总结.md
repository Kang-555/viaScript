## 核心模块详解

### 2. 网络嗅探器（Sniffer）

**工作原理**：通过劫持浏览器的网络请求来自动发现视频资源。

```
用户访问网页
    │
    ├─ fetch() 劫持 ──▶ 检测 Content-Type / URL 特征
    ├─ XHR 劫持 ──────▶ 检测响应头中的 Content-Type
    └─ Performance API ──▶ 每2秒扫描已加载资源
    │
    ▼
匹配规则：
  · m3u8: .m3u8后缀 或 application/x-mpegURL
  · mp4:  .mp4后缀 或 video/mp4
  · mov:  .mov后缀 或 video/quicktime
    │
    ▼
通过事件总线发送 video-found → UI 面板显示资源列表
```

### 3. AES-128 解密模块

```
M3U8 清单中的 EXT-X-KEY
    │
    ├─ METHOD=AES-128
    ├─ URI (密钥URL)
    └─ IV (可选初始化向量，默认用分片序号)
    │
    ▼
流程：
  1. 下载密钥文件（16字节）
  2. 解析 IV（优先使用清单中的 IV，否则用分片序号生成）
  3. 使用 Web Crypto API 的 AES-CBC 解密
  4. 返回解密后的 Uint8Array
```

### 4. M3U8 解析器

**解析流程**：

```
M3U8 文本
    │
    ├─ Master Playlist 检测（#EXT-X-STREAM-INF）
    │   └─ 自动选择最高码率的子清单
    │
    ├─ 逐行解析：
    │   ├─ #EXT-X-TARGETDURATION → 目标时长
    │   ├─ #EXT-X-KEY → 加密信息
    │   ├─ #EXT-X-MEDIA-SEQUENCE → 起始序号
    │   ├─ #EXTINF → 分片时长
    │   └─ URL行 → 分片地址
    │
    └─ 输出：segments[] + timeList[] + totalDuration
```

**时间→分片映射**：

```
用户指定时间范围 [beginSec, endSec]
    │
    ▼
遍历 timeList（每个分片的 tStart / tEnd）
    │
    ▼
找到覆盖该时间范围的分片索引 [startIdx, endIdx]
    │
    ▼
传递给下载引擎只下载目标分片
```

### 5. 下载引擎

**多线程下载**：

```
Config.maxThreads = 4（默认4线程并发）
    │
    ▼
Worker 模型：
  ┌─────────┬─────────┬─────────┬─────────┐
  │ Worker1 │ Worker2 │ Worker3 │ Worker4 │
  └────┬────┴────┬────┴────┬────┴────┬────┘
       │         │         │         │
       └──── index++ 任务队列 ─────┘
    │
    ▼
每个分片处理流程：
  1. HTTP 请求（带进度回调）
  2. 失败自动重试（指数退避，最多3次）
  3. AES-128 解密（如有加密）
  4. 写入缓冲区
    │
    ▼
所有分片完成 → 按序拼接 → 生成 TS 文件 → 触发下载
```

**进度显示**：
- 完成百分比
- 已下载分片数 / 总分片数
- 已下载字节数
- 下载速度（KB/s 或 MB/s）
- ETA 预计剩余时间
- 失败分片计数

### 6. 可视化拖拽选段

**交互流程**：

```
用户点击「预览并选择时间段」
    │
    ▼
加载 hls.js 并播放视频
    │
    ▼
显示拖拽编辑器（全屏覆盖）
    │
    ├─ 顶部：视频播放器
    ├─ 起始时间滑块（可拖拽）
    ├─ 结束时间滑块（可拖拽）
    └─ 确定按钮
    │
    ▼
拖拽滑块时：
  · 实时显示时间（HH:MM:SS）
  · 绿色填充显示选中区间
  · 视频跳转到对应时间点
  · 起始滑块不超过结束滑块
    │
    ▼
点击「确定」→ 返回 { startSec, endSec, startHms, endHms }
    │
    ▼
自动回填到下载面板的时间输入框
```

## 技术亮点

| 特性 | 实现方式 |
|------|---------|
| **样式隔离** | Shadow DOM，完全不受页面 CSS 污染 |
| **跨域请求** | 使用 GM_xmlhttpRequest 绕过浏览器 CORS 限制 |
| **移动端适配** | 检测 UserAgent，触屏友好的交互设计 |
| **性能优化** | 分片并发下载、指数退避重试、进度节流更新 |
| **兼容性** | hls.js + 原生 HLS 播放 fallback |
| **加密支持** | AES-128-CBC 解密，支持密钥 URL 和内联 IV |
| **断点续传** | 暂不支持，重新开始会从头下载 |

## 使用场景

1. **在线视频截取**：观看视频时拖拽选择感兴趣的片段下载
2. **课程录像裁剪**：下载课程中特定时间段的内容
3. **直播回放保存**：从直播回放中提取精彩片段
4. **视频素材采集**：批量采集网页上的视频资源
