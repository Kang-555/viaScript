# m3u8可视化拖拽选段下载

## 功能说明

### 核心功能
- **自动嗅探**：页面播放视频时自动捕获 m3u8/MP4 资源
- **可视化选段**：弹窗内嵌播放器，拖拽滑块选择时间段
- **AES-128解密**：自动获取密钥并解密加密分片
- **分片拼接**：下载选中分片并拼接为完整TS文件
- **时间戳修复**：修复拼接后PCR/PTS/DTS时间戳，避免播放器跳变

### 技术特性
- 33位PCR/PTS精度支持，避免32位位运算截断
- 异步分片下载，线程池并发
- 移动端/PC端自适应
- 无需Shadow DOM，直接DOM操作

### 颜色方案
- 主色调：`#4caf50` 绿色
- 背景：`rgba(0,0,0,0.88)` 半透明黑
- 头部渐变：`#1b5e20` → `#2e7d32`
- 标签：m3u8绿色 / MP4蓝色

### 交互说明
1. 点击资源项展开/收起详情
2. 拖拽滑块选择起止时间
3. 点击"确定回填时间"添加时间段
4. 可添加多个时间段
5. 点击"开始下载"执行任务
