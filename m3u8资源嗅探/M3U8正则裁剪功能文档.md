# M3U8正则裁剪

> 版本：1.0 | 适用：Tampermonkey + 1DM下载器

## 功能概述

粘贴M3U8链接，通过多时间段可视化筛选分片，自动生成用于1DM下载器的正则表达式。

## 面板说明

- **位置**：固定在页面**右下角底部**，避免遮挡视频
- **切换按钮**：点击"🔗 M3U8链接"或"⏱ 时间段筛选"展开/收起对应区域
- **时间段筛选**：两个独立进度条分别控制起始和结束位置
- **添加列表**：点击"➕ 添加到列表"将当前时间段添加到下方的段列表
- **段列表**：显示已添加的时间段，支持删除操作

## 使用流程

### 1. 解析M3U8

1. 在输入框粘贴M3U8链接
2. 点击 **解析**
3. 等待解析完成，显示分片统计信息

### 2. 设置时间段

- **可视化拖拽**：
  - 拖拽橙色**左手柄**调整起点
  - 拖拽橙色**右手柄**调整终点
  - 拖拽中间绿色区域可**整体平移**时间段
- **手动输入**：直接敲数字，自动补冒号
  - 输入 `000120` → 自动变为 `00:01:20`
  - 最多6位数字 `HHmmss`
- **添加时间段**：点击 `➕ 添加`，新段从上一段结束时间开始
- **删除时间段**：点击 `✕`，至少保留一个时间段

### 3. 生成正则

1. 点击 **预览筛选**：查看筛选后的分片数量
2. 点击 **生成正则**：自动生成正则表达式
3. 点击 **复制正则**：复制到剪贴板，粘贴到1DM下载器

## 正则生成规则

### 纯数字分片

按时间段分别生成正则，用 `|` 拼接：

```
时间段1: 分片 257471352-257471382
时间段2: 分片 257472161-257472242

生成示例：
(?:2574713(?:5[2-9]|[6-7]\d|8[0-2]))|(?:257472(?:1(?:6[1-9]|[7-8]\d|9[0-9])|2(?:0[0-9]|[1-3]\d|4[0-2])))
```

### 非数字分片

用 `|` 连接所有文件名并转义：

```
\b(?:seg_a|seg_b|seg_c)\b
```

### 算法特点

- 递归处理进位，避免 `[6-4]` 等非法字符类
- 按公共前缀分段，生成紧凑正则
- 每个时间段独立生成，互不干扰
- 数字边界断言 `(?<!\d)` 和 `(?!\d)`，防止匹配相邻数字

## 函数说明

| 函数 | 功能 |
|------|------|
| `parseM3u8(text, baseUrl)` | 解析M3U8文本，提取分片列表 |
| `filterByTimeRanges(segList, ranges)` | 按时间段筛选分片 |
| `generateRegexFromSegList(segList, ranges)` | 按时间段分别生成正则再拼接 |
| `buildNumericRangeRegex(min, max)` | 数字范围→正则，处理跨位数 |
| `buildSameLengthRegex(minStr, maxStr)` | 等长数字范围→正则 |
| `buildSuffixRegex(minS, maxS)` | 递归处理后缀，处理进位 |
| `commonPrefix(a, b)` | 提取公共前缀 |

## 注意事项

1. **跨域问题**：链接解析受浏览器同源策略限制，跨域时无法解析
2. **时间段校验**：开始时间必须早于结束时间
3. **正则有效性**：算法确保生成的正则无非法语法
4. **序号跳号**：正则算法假设时间段内分片序号连续，跳号时可能匹配到不存在的URL
5. **拖拽精度**：进度条按百分比映射到秒数，分片粒度取决于视频时长
