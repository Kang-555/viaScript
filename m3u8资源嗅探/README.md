# N_m3u8DL-RE 命令生成器 (油猴脚本)

> 解析 m3u8 → 拖动选时间段 → 一键生成下载命令  
> 保存名自动用当前网页标题（自动清洗非法字符）

## 使用步骤

```
 ① 打开有 m3u8 视频的网页
     │
     ▼
 ② 切到油猴脚本面板（或自动弹出，取决于脚本里有没有加触发按钮）
     │
     ▼
 ③ Tab1：粘贴 m3u8 链接 → 点「解析」
     │
     ▼
 ④ Tab2：拖起始/结束滑条 → 点「添加到列表」
         （可重复添加多段）
     │
     ▼
 ⑤ Tab3：点「生成命令」 → 点「复制命令」
     │
     ▼
 ⑥ 打开终端，cd 到 N_m3u8DL-RE 所在目录，粘贴执行
```

## 生成命令示例

```bash
./N_m3u8DL-RE "https://cdn.example.com/hls/episode12.m3u8" \
  --split-time-range "00:00:05-00:02:30" "00:08:15-00:10:00" \
  --save-name "某番剧 第12集"
```

- `./` 前缀 — 假定 N_m3u8DL-RE 在当前目录（Linux / macOS / Git Bash）
- `--save-name` 自动取网页 `<title>`，`\/:*?"<>|` 等非法字符会被替换为 `_`
- `--split-time-range` 支持多个时间段，全部剪切合并成一个文件

## 注意事项

| 问题 | 解决 |
|---|---|
| m3u8 跨域无法 fetch | 浏览器扩展环境下可能被 CORS 拦截，建议在脚本里加 `@connect *` 或在 Tampermonkey 设置里开启 |
| 命令生成后手动改路径 | Windows PowerShell 把 `./` 改成 `.\` 即可 |
| 保存名出现一堆下划线 | 网页标题本身包含大量特殊字符，属于正常清洗 |
