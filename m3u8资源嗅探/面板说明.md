# N_m3u8DL-RE 命令生成器 · 面板样式 v4.0

> 参考 `下载队列版.user.js` 面板风格  
> Shadow DOM 隔离样式 · 左下角固定 · **3 个 Tab**  
> 无标题栏、无图标、无进度条

## Tab 2：时间段（只管时间 + 文件名）

```
┌──────────────────────────────────────────┐
│ 嗅探          时间段          生成       │
├──────────────────────────────────────────┤
│ 📌 playlist_720p.m3u8                   │  ← 已选链接回显, 点击跳回嗅探
│                                         │
│ ── 时间范围 ──                          │
│                                         │
│   起始              结束                │
│   [003000]   —   [003023]              │
│                                         │
│   格式 HHMMSS (6位数字)                 │
│   清空两个框 = 全程下载                  │
│                                         │
│ ── 文件名 ──                            │
│                                         │
│   [某视频标题                      ]    │  ← 默认 document.title
│                                         │
│                                         │
│                                   [下一步→] │  ← 跳到「生成」tab
└──────────────────────────────────────────┘
```

**未选链接时**：
```
居中显示: ⚠️ 请先在嗅探 tab 选择一个 m3u8
```

**时间输入框**：
```
input type=text, inputmode=numeric, pattern=\d*
width:70px, font-family:monospace, font-size:12px, text-align:center
自动过滤非数字字符
```

**文件名输入框**：
```
input type=text, width:100%, padding:4px 6px
默认值: document.title → 过滤 \/:*?"<>| → _
```

**「下一步→」按钮**：
```
背景 transparent, border 1px solid #4caf50, color #4caf50, 靠右
点击 → 切到「生成」tab
```

## Tab 3：生成（命令预览 + 操作）

```
┌──────────────────────────────────────────┐
│ 嗅探          时间段          生成       │
├──────────────────────────────────────────┤
│ 📌 playlist_720p.m3u8                   │
│    00:30:00 - 00:30:23                  │  ← 时间摘要
│    文件名: 某视频标题                    │  ← 文件名摘要
│ ─────────────────────────────────────── │
│ ▶ 命令预览                              │
│ ┌─────────────────────────────────────┐ │
│ │ ~/test/N_m3u8DL-RE "https://...m3u8"│ │
│ │   --custom-range "00:30:00-00:30:23"│ │
│ │   --thread-count 8                 │ │
│ │   --download-retry-count 5         │ │
│ │   --no-log                         │ │
│ │   --save-dir ~/storage/downloads   │ │
│ │   --save-name "某视频标题"          │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ [📋 复制]            [💾 下载 nm_tpl.txt] │  ← 等宽按钮
│                                         │
└──────────────────────────────────────────┘
```

**未选链接时**：
```
居中显示: ⚠️ 请先在嗅探 tab 选择一个 m3u8
```

**命令预览框**：
```
textarea readonly, width:100%, min-height:80px
background:#0a0a1a, color:#6f9, border:1px solid #333
font-family:monospace, font-size:10px
任何输入变化 → 即时重渲染
```

**全程下载时的命令**（时间框清空）：
```
~/test/N_m3u8DL-RE "https://...m3u8" --thread-count 8 --download-retry-count 5 --no-log --save-dir ~/storage/downloads --save-name "某视频标题"
```

**操作按钮**：
```
[📋 复制]    主色背景 #4caf50, color #000 → GM_setClipboard → toast
[💾 下载]    transparent + border #4caf50 + color #4caf50 → Blob + a.click()
```

## 三个 Tab 的数据流向

```
嗅探 tab                    时间段 tab                   生成 tab
┌─────────────┐  选中链接   ┌─────────────────┐  填完参数   ┌─────────────────┐
│ 列表 → 点击  │──────────→│ 时间输入        │──────────→│ 命令预览        │
│             │  自动跳转  │ 文件名输入      │  自动跳转  │ 复制 / 下载     │
│ 手动粘贴    │            │ 下一步→ 按钮    │            │                 │
└─────────────┘            └─────────────────┘            └─────────────────┘

任何 tab 输入变化 → 命令预览实时重算
```

## 交互事件一览

| 事件 | 行为 |
|------|------|
| 嗅探到新 m3u8 | 自动追加到列表 |
| 点击列表项 | 选中 → 自动跳到「时间段」tab |
| 点「手动粘贴」 | prompt → 添加并选中 → 跳到「时间段」tab |
| 点击 tab | 切换内容区 |
| 点「下一步→」 | 跳到「生成」tab |
| 点 `×` | 隐藏面板（嗅探 hook 保留） |
| 时间输入变化 | 重算命令预览 |
| 文件名输入变化 | 重算命令预览 |
| 点「复制」 | `GM_setClipboard` → toast |
| 点「下载」 | Blob + a.click() → 浏览器自动重命名 |

## 文件输出规则

**每个 txt 文件只包含 1 条命令**（一行）  
**一个时间段**（`--custom-range` 或不加）  
文件名固定 `nm_tpl.txt`，浏览器重名自动加序号 → `nm_tpl (1).txt`、`nm_tpl (2).txt`...  
Termux 端 `~/a` 按文件名排序读取执行即可。
