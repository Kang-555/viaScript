# m3u8嗅探下载器 — 面板界面说明

## 整体结构

```
  （页面右下角，页面加载完自动出现）
  ┌──────────────────────────────────────────────┐
  │ [🔗链接] [⏱筛选] [⬇下载]          [—][×]   │  ← Tab 栏 + 最小化/关闭
  ├──────────────────────────────────────────────┤
  │                                              │
  │          （当前 Tab 的内容区）               │
  │                                              │
  └──────────────────────────────────────────────┘
```

- **宽度**：300px
- **定位**：`position:fixed; bottom:20px; right:20px`
- **主题色**：绿色 `#4caf50`（主页面）/ 粉色 `#e91e63`（iframe）
- **Shadow DOM**：样式隔离，不被页面 CSS 污染
- **最小化**：点击 `[—]` 缩为 32×32 圆形 `✂` 按钮；再次点击展开
- **关闭**：点击 `[×]` 彻底关闭，本页面生命周期内不再显示

## Tab 1：🔗 链接（嗅探资源列表）

```
  ┌──────────────────────────────────────────────┐
  │ [🔗链接] ●[⏱筛选] [⬇下载]          [—][×]   │
  ├──────────────────────────────────────────────┤
  │ 📡 当前页面已嗅探资源                        │
  │ ┌──────────────────────────────────────────┐ │
  │ │ [M3U8] 1080p_master.m3u8              →  │ │  ← 点击进入 Tab2
  │ └──────────────────────────────────────────┘ │
  │ ┌──────────────────────────────────────────┐ │
  │ │ [M3U8] 720p_alt.m3u8                  →  │ │
  │ └──────────────────────────────────────────┘ │
  │                                              │
  │ ✏️ 手动输入链接                              │
  │ ┌──────────────────────────────────────────┐ │
  │ │ https://example.com/playlist.m3u8        │ │
  │ └──────────────────────────────────────────┘ │
```

- 资源列表来自网络嗅探器（XHR/fetch 劫持）

- 解析失败会弹出 alert 错误信息

## Tab 2：⏱ 筛选（时间段设置）

### 初始状态（解析 m3u8 后自动进入）

```
  ┌──────────────────────────────────────────────┐
  │ [🔗链接] ●[⏱筛选] [⬇下载]          [—][×]   │
  ├──────────────────────────────────────────────┤
  │ 🎬 1080p_master.m3u8                         │
  │ 总时长: 01:23:45 | 分片数: 1256              │
  │                                              │
  │ ─────────●─────────────●──────────────────── │  ← 双滑块轨道
  │         00:00:00     00:01:00      01:23:45 │     (绿色高亮=选中区间)
  │                                              │
  │ 起始  [00:00:00]  ← 可点击编辑              │
  │ 结束  [00:01:00]                             │
  │ 单段时长: 00:01:00 (60.0s)                   │
  │                                              │
  │ [➕ 添加到列表]                              │
  │                                              │
  │ 📋 已添加时间段                              │
  │ 暂无时间段，点击上方➕添加                    │
  │                                              │
  │ 合计: 0段 | 0.0s | ~0分片                    │
  │ [→ 去下载]  ← 无时间段时灰化不可点            │
  └──────────────────────────────────────────────┘
```

### 拖拽滑块

```
  拖拽起始滑块 →         ●──────●─────────────────
                         ↑ 绿色区间实时跟随滑块
                         ↑ 时间标签实时更新

  拖拽结束滑块 →   ●──────────────●──────
                    ↑ 绿色区间扩大
```

- **鼠标拖拽**：按住白色圆形手柄拖动
- **触屏拖拽**：手机端触摸手柄拖动
- **点击跳转**：点击轨道任意位置，离哪个滑块近就跳哪个
- **互斥约束**：起始滑块永远 ≤ 结束滑块（差值 ≥ 0.5s）

### 编辑时间标签

```
  正常显示：                     点击后：
  ┌─────────────┐               ┌─────────────┐
  │ 00:01:30    │  ──点击──▶   │ 00:01:30    │  ← 变为输入框
  └─────────────┘               └─────────────┘
                                   ↑
                                   Enter 确认
                                   Escape 取消
                                   失焦自动提交
```

### 添加多个时间段后的状态

```
  ┌──────────────────────────────────────────────┐
  │ ...                                          │
  │ ─────────────────────●─────●──────────────── │  ← 上一段结束自动变为新起点
  │         00:01:00   00:02:00                   │
  │                                              │
  │ 📋 已添加时间段                               │
  │ ┌ 段1 ───────────────────────────────────[✕]┐│
  │ │ 00:00:00 → 00:01:00          60.0s       ││
  │ ├ 段2 ───────────────────────────────────[✕]┤│
  │ │ 00:01:00 → 00:02:00          60.0s       ││
  │ └───────────────────────────────────────────┘│
  │                                              │
  │ 合计: 2段 | 120.0s | ~47分片                  │
  │ [→ 去下载]  ← 已有时间段，可点击              │
  └──────────────────────────────────────────────┘
```

- 每次「➕ 添加到列表」后：
  - 起始时间自动 = 上一段结束时间
  - 结束时间默认 = 起始时间 + 60s（不超过总时长）
- 点击段列表中的 `✕` 删除该段
- 合计行实时统计段数、总时长、总分片数

### 下载流程状态

| 状态 | 进度条 | 按钮 | 文字 |
|------|--------|------|------|
| 待开始 | 0% | ▶ 开始下载 | 准备就绪 |
| 下载中 | 实时更新 | ■ 取消 + 禁用的「下载中...」 | 进度/速度/ETA |
| 完成 | 100% | 完成 | 下载完成! |
| 失败 | 停止 | 下载失败 | 错误: xxx |
| 取消 | 停止 | 恢复「开始下载」 | 错误: 已取消 |

## 交互规则

| 规则 | 说明 |
|------|------|
| Tab 解锁 | Tab2 需要先在 Tab1 选中资源；Tab3 需要先在 Tab2 添加时间段 |
| 连续选择 | 添加段后，起止时间自动衔接（上一段结尾 → 结尾+60s） |
| 最小时间间隔 | 起止时间最小间隔 0.5s，防止滑块交叉 |
| 总时长限制 | 所有时间自动 clamp 到 `[0, totalDuration]` |
| Shadow DOM 隔离 | 面板样式完全隔离，不受页面 CSS 影响 |
| 断点续传 | 不支持，重新开始会从头下载 |
| 取消下载 | 即时中断，已下载的数据丢弃 |

## 数据流向

```
  Tab1 (链接)                     Tab2 (筛选)                    Tab3 (下载)
  ┌──────────┐                   ┌──────────┐                   ┌──────────┐
  │ 嗅探列表  │ ──解析m3u8──▶    │ 解析结果  │ ──添加段──▶   │ cutSegs  │
  │ 手动输入  │                   │ 双滑块    │                   │ MultiSeg │
  └──────────┘                   │ 时间编辑  │                   │ Download │
                                 └──────────┘                   └──────────┘
                                                                     │
                                                        ┌────────────┴────────────┐
                                                        ▼                         ▼
                                                  VideoWriter  →  TS 文件下载
```
