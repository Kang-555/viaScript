# 新标签页预览 - 需求说明

## 概述

在网页中嗅探 m3u8 / mp4 视频资源，发现后弹出浮层面板，用户点击"预览"按钮即可在**新标签页**中打开视频播放器进行预览。

## 核心流程

```
页面加载 → 嗅探器启动 → 监听 Fetch/XHR/Performance
                              ↓
                     发现 m3u8 / mp4 URL
                              ↓
                     浮层面板显示资源列表
                              ↓
                     用户点击「预览」按钮
                              ↓
                  新标签页打开 HLS.js 播放器
                              ↓
                     播放视频流
```

## 功能需求

### 1. 资源嗅探

| 项 | 说明 |
|---|---|
| 嗅探类型 | m3u8、mp4、mov |
| 嗅探方式 | Hook fetch、Hook XMLHttpRequest、轮询 Performance API |
| 去重 | 按 URL path（不含 query）去重 |
| 排除 | data:、blob: 协议；图片/字体/CSS/JS 资源 |

### 2. 浮层面板

| 项 | 说明 |
|---|---|
| 位置 | 左下角 fixed 悬浮 |
| 折叠 | 圆形按钮切换显示/隐藏 |
| 条目 | 展示类型标签、文件名、URL |
| 操作 | 「预览」按钮打开新标签页 |

### 3. 新标签页预览

| 项 | 说明 |
|---|---|
| 播放器 | HLS.js（CDN 引入，m3u8） / 原生 `<video>`（mp4） |
| 打开方式 | `Blob` → `URL.createObjectURL` → `window.open(url, '_blank')` |
| 预览信息 | 原始地址、加密状态、分片总数、总时长 |
| 全宽适配 | 视频 `width:100vw` 出血铺满，内容区独立 padding |
| 移动端 | `playsinline` + `webkit-playsinline`，iOS 不强制全屏 |

### 4. 新标签页面板结构

#### 4.1 整体布局（视频出血式全宽）

│                                                              │

│  header  (padding:12px, bg:#16213e)                         │
│  ┌────────────────────────────────────────────────────┐     │
│  │  M3U8 预览  /  视频预览                            │     │
│  └────────────────────────────────────────────────────┘     │
├──────────────────────────────────────────────────────────────┤
│  info  (padding:12px, bg:#1a1a2e)                           │
│  ┌──────────────────┐  ┌──────────────────┐  (桌面≥600px)  │
│  │ 原始地址          │  │ 加密状态          │                │

#### 4.2 DOM 结构（m3u8）

```
<body>
├── <video id="player" controls autoplay playsinline webkit-playsinline>
│       ↑ 100vw 全宽出血，line-height:0 消除底部间隙
├── <button class="back-btn">关闭</button>
│       ↑ position:fixed; 右上角; 半透明毛玻璃
├── <div class="header">
│   └── <h2>M3U8 预览</h2>
└── <div class="info">
    ├── <div>原始地址 + 链接
    ├── <div>加密状态（加密红 / 未加密绿）
    ├── <div>分片总数
    └── <div>总时长
```

#### 4.3 DOM 结构（mp4）

```
<body>
├── <video id="player" controls autoplay playsinline webkit-playsinline src="{url}">
├── <button class="back-btn">关闭</button>
├── <div class="header">
│   └── <h2>视频预览</h2>
└── <div class="info">
    └── <p>原始地址 + 链接
```

#### 4.4 关键 CSS

| 选择器 | 属性 | 作用 |
|---|---|---|
| `html,body` | `width:100%; min-height:100vh` | 消除默认 margin，根元素撑满 |
| `body` | `-webkit-text-size-adjust:100%` | 防止横屏文字自动放大 |
| `video` | `display:block; width:100vw; height:auto; line-height:0` | 视频全宽出血，按比例自适应高度 |
| `.header` | `padding:12px; background:#16213e` | 内容区独立内边距，不影响视频 |
| `.info` | `padding:12px; display:grid` | 信息区网格布局 |
| `@media(min-width:600px)` | `.info{grid-template-columns:1fr 1fr}` | 桌面端双列 |
| `.back-btn` | `position:fixed; backdrop-filter:blur(5px)` | 浮动关闭按钮 |

#### 4.5 移动端适配

| 问题 | 解决方案 |
|---|---|
| 视口缩放错乱 | `<meta viewport="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">` |
| iOS 强制全屏播放 | `playsinline` + `webkit-playsinline` |
| 视频宽度被 padding 限制 | 视频用 `100vw`（视口单位）而非 `100%`（父容器百分比） |
| 视频底部基线间隙 | `line-height:0` |
| 横屏文字放大 | `-webkit-text-size-adjust:100%` |

#### 4.6 预览页面关键逻辑

```javascript
const video = document.getElementById('player');
let currentHls = null;

function loadVideo(src) {
  if (currentHls) { currentHls.destroy(); currentHls = null; }
  if (Hls.isSupported()) {
    currentHls = new Hls();
    currentHls.loadSource(src);
    currentHls.attachMedia(video);
    currentHls.on(Hls.Events.MANIFEST_PARSED, () => video.play().catch(() => {}));
    currentHls.on(Hls.Events.ERROR, (evt, data) => {
      if (data.fatal) video.play().catch(() => {});  // fatal 错误降级重试
    });
  } else if (video.canPlayType('application/vnd.apple.mpegurl')) {
    video.src = src;  // Safari 原生 HLS 支持
    video.play().catch(() => {});
  } else {
    document.body.innerHTML += '<p>当前浏览器不支持 HLS 播放</p>';
  }
}

loadVideo(url);
```

#### 4.7 预览页生命周期

```
1. 用户点击「新标签预览」
       ↓
2. 若为 m3u8 → GM_xmlhttpRequest 解析 m3u8（获取分片数/时长/加密状态）
       ↓
3. 构建 HTML 字符串（内嵌 HLS.js CDN + 内联 CSS）
       ↓
4. new Blob([html], {type:'text/html'}) → URL.createObjectURL(blob)
       ↓
5. window.open(blobUrl, '_blank')  ← 新标签页打开
       ↓
6. 新标签页加载 → HLS.js / <video> 初始化 → 自动播放
       ↓
7. setTimeout(60s) → URL.revokeObjectURL(blobUrl)  ← 回收 Blob
```
