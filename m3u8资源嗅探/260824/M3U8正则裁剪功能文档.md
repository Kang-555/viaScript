# M3U8正则裁剪

> 版本：1.0 | 适用：Tampermonkey + 1DM下载器

## 功能概述

粘贴M3U8链接，通过可视化进度条设置多时间段筛选分片，自动生成用于1DM下载器的正则表达式。

## 面板说明

- **位置**：固定在页面**左下角底部**，避免遮挡视频
- **三标签页切换**：点击顶部标签切换对应功能区域
  - 🔗 **M3U8链接**：解析M3U8文件，显示分片统计
  - ⏱ **时间段筛选**：双进度条独立控制起止时间，点击时间可手动输入
  - 🔍 **正则**：预览筛选结果，生成并复制正则
- **时间段筛选**：
  - 起始/结束两个独立进度条，可拖拽或点击跳转
  - 时间标签可点击切换为编辑模式手动输入 `HH:MM:SS`
  - 进度条实时显示当前时间
- **添加列表**：点击「➕ 添加到列表」将当前时间段写入下方的段列表
- **段列表**：初始隐藏，添加后显示，支持删除操作

## 使用流程

### 1. 解析M3U8

1. 在「🔗 M3U8链接」页粘贴M3U8链接
2. 点击 **解析**
3. 等待解析完成，自动跳转至「⏱ 时间段筛选」页
4. 显示分片统计（总分片/总时长/平均分片时长）

### 2. 设置时间段

- **拖拽进度条**：
  - 拖拽起始进度条滑块调整起点
  - 拖拽结束进度条滑块调整终点
  - 点击进度条任意位置可快速跳转
- **手动输入时间**：
  - 点击时间标签（如 `00:01:30`）切换为编辑模式
  - 直接输入 `HH:MM:SS` 格式
  - 按 **Enter** 确认，**Escape** 取消
- **添加时间段**：
  - 点击「➕ 添加到列表」保存当前起止时间
  - 自动将起始时间设为上一段结束时间，便于连续选择
- **删除时间段**：点击段列表中的「✕」

### 3. 生成正则

1. 切换到「🔍 正则」页
2. 点击 **预览筛选**：查看筛选后的分片数量
3. 点击 **生成正则**：自动生成正则表达式
4. 点击 **复制正则**：复制到剪贴板，粘贴到1DM下载器
5. 或点击 **复制URL**：复制所有匹配的分片URL

## 数据模型

```javascript
// 已添加的时间段列表
timeRanges = [
  { start: 0, end: 60 },      // 段1
  { start: 300, end: 360 },   // 段2
];

// 当前编辑中的临时时间（未添加到列表）
timeRanges._curStart = 0;     // 当前起始
timeRanges._curEnd = 60;      // 当前结束
```

- `timeRanges` 数组存储已确认的段
- `_curStart` / `_curEnd` 存储正在编辑的临时值
- 拖拽进度条或编辑时间 → 修改 `_curStart`/`_curEnd`
- 点击「添加到列表」→ 将临时值 push 进 `timeRanges` 数组

## 正则生成规则

### 纯数字分片

按时间段分别生成正则，用 `|` 拼接：

```
时间段1: 分片 257471352-257471382
时间段2: 分片 257472161-257472242

生成示例：
(?<!\d)(?:2574713(?:5[2-9]|[6-7]\d|8[0-2]))(?!\d)|(?<!\d)(?:257472(?:1(?:6[1-9]|[7-8]\d|9[0-9])|2(?:0[0-9]|[1-3]\d|4[0-2])))(?!\d)
```

### 非数字分片

用 `|` 连接所有文件名并转义：

```
\b(?:seg_a|seg_b|seg_c)\b
```

### 算法特点

- 递归处理进位，避免 `[6-4]` 等非法字符类
- 按公共前缀分段，生成紧凑正则
- 每个时间段独立生成，互不干扰
- 数字边界断言 `(?<!\d)` 和 `(?!\d)`，防止匹配相邻数字

## 函数说明

| 函数 | 功能 |
|------|------|
| `timeToSec(str)` | 时间字符串 `HH:MM:SS` → 秒数 |
| `secToTime(sec)` | 秒数 → 时间字符串 `HH:MM:SS` |
| `parseM3u8(text, baseUrl)` | 解析M3U8文本，提取分片列表 |
| `filterByTimeRanges(segList, ranges)` | 按时间段筛选分片（去重） |
| `generateRegexFromSegList(segList, ranges)` | 按时间段分别生成正则再拼接 |
| `buildNumericRangeRegex(min, max)` | 数字范围→正则，处理跨位数 |
| `buildSameLengthRegex(minStr, maxStr)` | 等长数字范围→正则 |
| `buildSuffixRegex(minS, maxS)` | 递归处理后缀，处理进位 |
| `commonPrefix(a, b)` | 提取公共前缀 |
| `renderTimeRanges()` | 渲染段列表UI |
| `updateRangeUI()` | 更新进度条和时间显示 |
| `syncFilter()` | 同步筛选并返回结果 |

## 注意事项

1. **跨域问题**：链接解析受浏览器同源策略限制，跨域时无法解析
2. **时间段校验**：结束时间必须大于起始时间
3. **正则有效性**：算法确保生成的正则无非法语法
4. **序号跳号**：正则算法假设时间段内分片序号连续，跳号时可能匹配到不存在的URL
5. **拖拽精度**：进度条按百分比映射到秒数，精度取决于视频时长
6. **单段操作**：每次拖拽/编辑只影响当前临时时间段，不修改已保存的段
