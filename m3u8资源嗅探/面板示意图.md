# M3U8 嗅探下载器 — 面板示意图

> 脚本注入的悬浮面板，固定在页面底部左侧，支持 3 个 Tab 切换。
> 宽：340px（或 `100vw - 20px`，移动端自适应） | 最大高：400px | 黑底 + 主色边框

---

## 整体结构

```
┌─────────────────────────────────────────────────────┐
│  [嗅探资源]   [下载配置]   [下载队列]               × │  ← Tab Header（固定）
├─────────────────────────────────────────────────────┤
│                                                     │
│              当前 Tab 面板内容                       │  ← Tab Body（可滚动）
│                                                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

---

## Tab 2：下载配置

**没有选择资源时**（从 Tab 1 直接切过来）：
```
┌─────────────────────────────────────────────────────┐
│  嗅探资源     [下载配置]   [下载队列]               × │
├─────────────────────────────────────────────────────┤
│                                                     │
│              请先在嗅探面板选择一个资源              │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**选择 M3U8 资源后**：
```
┌─────────────────────────────────────────────────────┐
│  嗅探资源     [下载配置]   [下载队列]               × │
├─────────────────────────────────────────────────────┤
│                                                     │
│  video_12345.m3u8                        ← 可点击编辑│
│  类型: M3U8 | 时长: 12:30 | 分片: 156 | 未加密       │
│                                                     │
│  ── 下载范围 ──                                      │
│  ○ 时间  [000000] - [001230]                         │
│  ○ 切片  [  0   ] - [  155  ]                        │
│                                                     │
│  ┌─────────────────────────────────────────────────┐ │
│  │  加入下载队列                                   │ │
│  │  [返回嗅探]                                     │ │
│  └─────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

**选择 MP4 资源后**（隐藏下载范围）：
```
┌─────────────────────────────────────────────────────┐
│  嗅探资源     [下载配置]   [下载队列]               × │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ad_trailer.mp4                         ← 可点击编辑│
│  类型: MP4 | --:--                                   │
│                                                     │
│  ┌─────────────────────────────────────────────────┐ │
│  │  加入下载队列                                   │ │
│  │  [返回嗅探]                                     │ │
```

- 点击**文件名** → 弹出 textarea 编辑文件名（回车确认，Shift+回车换行）
- 切换 ○ 时间/切片 → 对应输入框启用/禁用
- 点击 **[加入下载队列]** → 入队，按钮变 "已入队 #1" 1.5 秒后恢复

**队列为空时**：
```
┌─────────────────────────────────────────────────────┐
│  嗅探资源     下载配置     [下载队列]               × │
├─────────────────────────────────────────────────────┤
│  队列: 0 | 下载中 0 | 等待 0           [全部移除]  │
├─────────────────────────────────────────────────────┤
│                                                     │
│                   队列为空                          │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**有任务时**：
```
┌─────────────────────────────────────────────────────┐
│  嗅探资源     下载配置     [下载队列]               × │
├─────────────────────────────────────────────────────┤
│  队列: 3 | 下载中 1 | 等待 1 | 完成 1   [全部移除]  │
├─────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────┐ │
│ │ video_12345.m3u8    [下载中]                     │ │
│ │ 00:02 | 45% | 2.1MB/4.7MB | 2.3MB/s              │ │
│ ├─────────────────────────────────────────────────┤ │
│ │ live_stream.m3u8    [等待中]                     │ │
│ │ --:-- | 等待下载启动                              │ │
│ ├─────────────────────────────────────────────────┤ │
│ │ ad_trailer.mp4      [已完成]                     │ │
│ │ 00:15 | 3.8MB  ✓                                │ │
```

- 状态颜色：`等待中` 灰蓝 / `下载中` 主色绿 / `已完成` 蓝 / `失败` 红 / `已取消` 灰
- 实时更新：进度、时间、速度由 `UIProxy` 驱动，切走 Tab 再切回不丢状态

## DOM 结构总览（对应代码）

```
#gm-sniffer-v2-ts                    ← host（固定定位）
└── #shadowRoot
    ├── <style>                      ← buildStyles()
    └── .main-panel                  ← this.$.root
        ├── .tab-header              ← this.$.tabHeader
        │   ├── button.tab-btn.active[data-tab="sniffer"]
        │   ├── button.tab-btn[data-tab="download-setting"]
        │   ├── button.tab-btn[data-tab="queue"]
        │   └── span.close-btn
        └── .tab-body                ← this.$.tabBody
            ├── .tab-panel.active[data-panel="sniffer"]    ← this.$.panelSniffer
            │   └── (由 snifferTab.ensurePanel 动态填充)
            │       ├── .queue-header-bar > button.head-btn
            │       ├── .sniffer-list
            │       │   ├── .empty-tip
            │       │   └── .sniffer-item*N（委托到父容器）
            │       └── .sniffer-status
            ├── .tab-panel[data-panel="download-setting"]  ← this.$.panelSetting
            │   └── (由 setting.ensurePanel 动态填充)
            │       └── .setting-body
            │           ├── .filename-edit           ← 可点击 → textarea.filename-input
            │           ├── .setting-info
            │           ├── .setting-m3u8（MP4时隐藏）
            │           │   └── .mode-row（radio + input*）
            │           └── .btn-row
            │               ├── .btn-queue-add
            │               └── .btn-back-sniff
            └── .tab-panel[data-panel="queue"]             ← this.$.panelQueue
                └── (由 queueUI.ensurePanel 动态填充)
                    ├── .queue-header-bar
                    │   ├── span（统计文本）
                    │   └── .btn.btn-clear-all
```

## CSS 变量（可通过 Config.primaryColor 改色）

| 变量 | 默认值 | 用途 |
|---|---|---|
| `--p` | `#4caf50`（顶层）/ `#e91e63`（iframe） | 主色：Tab激活、按钮、类型标签、下载中状态 |
| `--bg` | `rgba(0,0,0,.85)` | 面板背景 |
| `--text` | `#fff` | 主文字 |
| `--dim` | `#aaa` | 次文字（时长/进度/提示） |
| `--divider` | `rgba(255,255,255,.08)` | 分割线 |
| `--danger` | `#f44336` | 危险色：失败/全部移除按钮 |
| `--info` | `#2196F3` | 信息色：MP4类型/已完成状态 |
| `--warn` | `#ff9800` | 警告色：取消按钮 |

## 交互流程

```
  页面加载
     │
     ▼
  sniffer.start()  ← 自动开始嗅探
     │
     ▼
  UI.init() → 创建根 DOM → snifferTab.ensurePanel()
     │
     ▼
  ┌─ 嗅探到视频 ──────────────────────────────┐
  │  Bus.emit('video-found', data)            │
  │    → snifferTab.addResource(data)         │
  │      ├── 创建 .sniffer-item DOM          │
  │      ├── 状态条更新                       │
  │      └── M3U8 → parseResourceInfo() 异步 │
  │           → 完成后 updateRow() 更新行信息  │
  └──────────────────────────────────────────┘
     │
     ▼
  ┌─ 点击"选择" ──────────────────────────────┐
  │  selectResource(item)                      │
  │    → settingItem = item                    │
  │    → switchTab('download-setting')        │
  │    → setting.render()                      │
  └──────────────────────────────────────────┘
     │
     ▼
  ┌─ 点击"加入下载队列" ───────────────────────┐
  │  setting.addToQueue(btn)                   │
  │    → ui.queue.addTask(item, opt)           │
  │    → Bus.emit('queue:task-added', task)    │
  │      → queueUI.onAdded(task)               │
  │        → 创建 .queue-row DOM               │
  │        → 创建 UIProxy 绑定实时更新         │
  └────────────────────────────────────────────┘
```
