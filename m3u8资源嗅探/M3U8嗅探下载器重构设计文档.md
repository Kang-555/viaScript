# M3U8嗅探下载器 - 面板重构设计文档

> 版本：2.4 | 适用：Tampermonkey + Via/Kiwi浏览器

## 重构目标

将原单列表式面板升级为**三标签页结构**，整合「嗅探资源 → 时间段筛选 → 下载」完整流程。

## 实现思路

### 1. UI类重构

```javascript
class UI {
  constructor() {
    this.currentTab = 'resources';    // 当前标签页
    this.currentResource = null;      // 选中的M3U8资源详情
    this.timeRanges = [];              // 已添加的时间段
    this.timeRanges._curStart = 0;    // 临时起始
    this.timeRanges._curEnd = 0;      // 临时结束
    this.downloadState = null;        // 下载进度
  }

  renderTab(tabName) { ... }          // 切换标签页渲染
  renderResourceList() { ... }        // 标签1：资源列表
  renderRangeEditor() { ... }         // 标签2：时间段筛选
  renderDownloadPanel() { ... }       // 标签3：下载
}
```

### 2. 关键方法

| 方法 | 功能 |
|------|------|
| `switchTab(name)` | 切换标签页，渲染对应内容 |
| `selectResource(url)` | 选择资源，自动解析M3U8，跳转筛选页 |
| `parseSelectedResource()` | 解析选中资源的M3U8，获取分片和时长 |
| `updateRangeUI()` | 刷新双进度条和时间显示 |
| `addTimeRange()` | 将临时时间添加到段列表 |
| `startDownload()` | 开始下载任务 |
| `updateDownloadProgress()` | 实时更新下载进度 |

### 3. 双进度条交互

```
事件绑定:
  startTrack.mousedown → startDragging = true
  endTrack.mousedown   → endDragging = true
  document.mousemove   → handleTrackDrag(e, isStart)
  document.mouseup     → 重置 dragging 状态

拖拽逻辑:
  1. 计算鼠标在轨道上的百分比
  2. 映射为秒数: sec = pct * totalDuration
  3. 更新 _curStart 或 _curEnd
  4. 刷新进度条UI

时间编辑:
  1. 点击时间文字 → contenteditable = true
  2. 输入 HH:MM:SS
  3. Enter/blur → 解析并保存
  4. Escape → 取消还原
```

### 4. 下载流程

```
用户点击「开始下载」
  → 校验: 是否有资源 + 是否有时间段
  → 根据 timeRanges 计算需要下载的分片范围
  → 调用 TaskRunner(url, 'm3u8', btn, { beginSec, endSec })
  → 监听 onProgress 回调更新UI
  → 下载完成显示结果
```

### 5. ShadowDOM适配

- 新面板仍使用 ShadowDOM 隔离样式
- 标签页结构在 ShadowDOM 内渲染
- 拖拽事件绑定在 ShadowRoot 内元素
- `document.mousemove/mouseup` 仍绑定到宿主 document

## 与原脚本的差异

| 对比项 | 原版 | 重构版 |
|--------|------|--------|
| **布局** | 单列表展开 | 三标签页切换 |
| **时间设置** | 文本框手动输入 | 双进度条可视化拖拽 |
| **多段选择** | 不支持 | 支持多时间段叠加 |
| **资源管理** | 列表展开下载 | 单独资源选择页 |
| **下载入口** | 每个资源独立按钮 | 统一下载面板 |
| **进度展示** | 按钮文字更新 | 独立进度面板 |
