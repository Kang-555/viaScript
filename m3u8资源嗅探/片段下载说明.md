# 1DM HLS 片段裁剪 使用说明

## 功能

裁剪 M3U8 指定时间段，生成新的 M3U8 文件，唤起 1DM（Internet Download Manager）完成后续的下载 / 解密 / 合并。

**脚本职责**：仅裁剪 M3U8 文本（几 KB），不下载任何分片，不解密，不拼接。
**1DM 职责**：读取裁剪后的 M3U8 → 下载分片 → 拉密钥解密 → 合并输出完整视频。

## 适用环境

| 项目 | 要求 |
|------|------|
| 浏览器 | Via 浏览器（Android） |
| 脚本引擎 | Tampermonkey / Violentmonkey |
| 下载工具 | 1DM（需支持 `1dm://` 协议） |
| HTTPS | 目标站点必须为 HTTPS |

## 安装

1. 打开 Via 浏览器 → 扩展管理 → 导入脚本
2. 选择 `片段下载.user.js`
3. 脚本自动在所有页面生效

## 使用步骤

### 1. 打开目标页面

打开包含 HLS 视频的页面（如直播页、点播页）。

### 2. 等待视频加载

页面右上角会出现悬浮面板：

```
┌─────────────────────────────────┐
│ ● 1DM HLS 片段裁剪              │
│                                 │
│ M3U8 地址                       │
│ ┌─────────────────────────────┐ │
│ │ https://cdn.example.com/v.m3u8│ │ ← 自动填充
│ └─────────────────────────────┘ │
│                                 │
│ 开始(秒)  结束(秒)              │
│ ┌──────┐ ┌──────┐              │
│ │  0   │ │  60  │              │
│ └──────┘ └──────┘              │
│                                 │
│ [0-30s] [30-60s] [1-2min]      │ ← 快捷预设
│                                 │
│ ┌─────────────────────────────┐ │
│ │ ✂️ 裁剪 M3U8 → 1DM 下载     │ │ ← 点击触发
│ └─────────────────────────────┘ │
│                                 │
│ 脚本仅裁剪 · 解密/下载/合并由1DM完成 │
└─────────────────────────────────┘
```

### 3. 设置时间范围

- **方式 A**：直接输入秒数（如 `30` 和 `120`，即 30秒~2分钟）
- **方式 B**：点击预设按钮（0-30s / 30-60s / 1-2min）

### 4. 点击「裁剪 M3U8 → 1DM 下载」

脚本将：
1. 拉取原始 M3U8 文本
2. 解析并映射时间段 → 分片索引
3. 生成新的裁剪后 M3U8
4. 通过 `1dm://` 协议唤起 1DM
5. 1DM 弹出下载确认窗口

### 5. 在 1DM 中确认

1DM 会显示待下载的分片列表，确认后开始下载。

## 关键设计说明

### 时间 → 分片映射

M3U8 分片是固定时长的数据包（通常 2~10 秒），边界无法精确裁切：

```
用户选择: 30s ~ 65s

分片  0-10s  10-20s  20-30s  30-40s  40-50s  50-60s  60-70s  70-80s
                                   ↑                       ↑
                               startIdx=3              endIdx=6

实际下载: 30s ~ 70s (包含 65s~70s 的冗余部分)
```

这是 TS 格式的固有特性，无法避免。

### 密钥保留

如果原始 M3U8 包含 `#EXT-X-KEY:METHOD=AES-128,URI="..."`，脚本会：
1. 将 URI 绝对化（拼接成完整 URL）
2. 原样复制到裁剪后的 M3U8 中
3. 1DM 读取该标签，自行拉取密钥完成解密

### 1DM 触发机制

脚本使用双重触发确保兼容性：

```javascript
// 方式 A：1dm:// 协议（Via 原生支持）
window.location.href = `1dm://${encodeURIComponent(dataUri)}`;

// 方式 B：<a download> 兜底
a.href = dataUri;
a.download = filename;
a.click();
```

## 常见问题

### Q: M3U8 地址没自动填充？

脚本检测 `<video>` 标签的 `src` 属性。如果使用 HLS.js 等播放器，URL 可能不在 `src` 中。此时请手动粘贴 M3U8 链接。

### Q: 1DM 没弹出下载框？

1. 确认 Via 已关联 1DM
2. 确认 1DM 已安装并启用 Via 集成
3. 尝试点击面板底部的下载链接（兜底方案）

### Q: 下载的视频时间段不准？

TS 分片是固定时长的数据包，无法精确到秒级裁切。实际下载范围会略大于选择范围（通常多 0~10 秒）。

### Q: 加密视频能裁剪吗？

可以。脚本保留 `#EXT-X-KEY` 行，1DM 会自行拉取密钥解密。但如果密钥服务器有防盗链，1DM 可能无法获取密钥。

### Q: 支持多码率（Master Playlist）吗？

暂不支持。如果输入的是 Master Playlist（包含 `#EXT-X-STREAM-INF`），需要先获取 Media Playlist 的 URL。
