# 数字正则裁剪.user.js 修改说明

> 版本：2.1 → 2.2 | 修改日期：2026-08-26

## 修改目标

1. **添加自动嗅探M3U8链接功能** - 无需手动粘贴链接，自动拦截网页中的m3u8请求
2. **去掉进度条** - 时间段筛选改为 `number` 类型输入框，支持 `000000` 格式（HHMMSS）

## 修改内容

### 1. 自动嗅探功能

**新增：**
- 拦截 `XMLHttpRequest` 和 `fetch` 请求
- 自动检测 `.m3u8` 链接或 `application/vnd.apple.mpegurl` 类型
- 嗅探到m3u8后自动解析并填充到面板
- 去重机制，避免重复解析同一链接

**实现方式：**
```javascript
// 拦截fetch
const originalFetch = window.fetch;
window.fetch = async (...args) => {
    const url = args[0] instanceof Request ? args[0].url : args[0];
    if (url.includes('.m3u8')) {
        handleM3u8Found(url);
    }
    return originalFetch.apply(window, args);
};

// 拦截XHR
class HijackedXHR extends XMLHttpRequest {
    open(method, url, ...args) {
        if (url.includes('.m3u8')) {
            handleM3u8Found(url);
        }
        super.open(method, url, ...args);
    }
}
```

### 2. 去掉进度条，改为number输入

**原设计：**
- 起始/结束两个进度条（可拖拽）
- 时间标签可点击编辑（contenteditable）

**新设计：**
- 起始/结束两个 `input[type="number"]` 输入框
- 支持 `000000` 格式（HHMMSS）
- 自动补零：输入 `130` → 显示 `000130` → 解析为 00:01:30
- 仅支持数字键盘，无法输入字母或符号

**HTML变更：**
```html
<!-- 旧版 -->
<div class="range-group">
  <span class="range-label">起始</span>
  <span class="range-time-edit" id="startTimeEdit">00:00:00</span>
  <div class="video-track" id="startTrack">
    <div class="video-progress" id="startProgress"></div>
    <div class="video-thumb" id="startThumb"></div>
  </div>
</div>

<!-- 新版 -->
<div class="time-input-row">
  <span class="time-label">起始</span>
  <input type="number" id="timeStart" min="0" max="235959" 
         value="000000" placeholder="HHMMSS" class="time-input">
  <span class="time-sep">-</span>
  <span class="time-label">结束</span>
  <input type="number" id="timeEnd" min="0" max="235959" 
         value="000100" placeholder="HHMMSS" class="time-input">
</div>
```

**JS变更：**
- 删除所有进度条拖拽相关代码（`handleTrackDrag`、`mousedown/mousemove/mouseup` 事件）
- 删除 `video-track`、`video-progress`、`video-thumb` 相关CSS
- 新增 `parseTimeInput(str)` 函数，将 `000000` 格式转为秒数
- 输入框 `onchange` 事件直接更新时间值

### 3. 时间解析函数

```javascript
function parseTimeInput(str) {
    if (!str) return 0;
    const s = String(str).padStart(6, '0');
    if (s.length !== 6) return 0;
    const h = parseInt(s.substring(0, 2)) || 0;
    const m = parseInt(s.substring(2, 4)) || 0;
    const sec = parseInt(s.substring(4, 6)) || 0;
    return h * 3600 + m * 60 + sec;
}

function formatTimeInput(seconds) {
    const h = Math.floor(seconds / 3600).toString().padStart(2, '0');
    const m = Math.floor((seconds % 3600) / 60).toString().padStart(2, '0');
    const s = Math.floor(seconds % 60).toString().padStart(2, '0');
    return h + m + s;
}
```

## 注意事项

1. **自动嗅探跨域限制** - 浏览器同源策略可能阻止跨域m3u8请求的拦截
2. **输入格式校验** - 输入框限制 `0-235959`，但需额外校验时间合法性（如 `006000` 无效）
3. **进度条CSS清理** - 删除所有 `.video-track`、`.video-progress`、`.video-thumb` 相关样式
4. **拖拽事件清理** - 删除 `mousedown/mousemove/mouseup` 事件监听
