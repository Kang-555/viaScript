# m3u8嗅探下载器

> 网页 m3u8 嗅探下载器 | TS 分片直接拼接 | AES-128 解密 | 适配 Via/Kiwi 手机浏览器

---

## 一、功能概述

| 功能 | 说明 |
|------|------|
| 自动嗅探 | Hook Fetch/XHR/Performance，自动捕获页面 m3u8/mp4/mov 资源 |
| TS 直拼 | 分片直接拼接为 `.ts` 文件，无需 ZIP 打包 |
| AES-128 解密 | 自动提取密钥并解密加密分片 |
| 范围下载 | 支持按**分片序号**或**时间范围**裁剪下载 |
| 多线程并发 | 默认 4 线程并发下载，支持失败自动重试 |
| 移动端适配 | 自动检测设备类型，移动端优先调用浏览器原生下载 |

## 四、核心接口

### 4.1 TaskRunner（任务入口）

```javascript
window.TaskRunner(url, type, btn, opt)
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `url` | string | 视频资源地址 |
| `type` | string | `'m3u8'` 或 `'mp4'` |
| `btn` | HTMLElement | 进度显示按钮元素 |
| `opt.startIdx` | number | 起始分片序号（可选） |
| `opt.endIdx` | number | 结束分片序号（可选） |
| `opt.beginSec` | number | 起始秒数（可选） |
| `opt.endSec` | number | 结束秒数（可选） |

### 4.2 parseM3u8（解析函数）

```javascript
parseM3u8(url) → { url, segments, timeList, totalDuration, targetDuration }
```

| 返回字段 | 说明 |
|----------|------|
| `url` | 最终解析的 M3U8 地址（可能经过多码率切换） |
| `segments` | 分片数组，每项含 `url / key / iv / seq / dur` |
| `timeList` | 时间索引，每项含 `idx / dur / tStart / tEnd` |
| `totalDuration` | 视频总时长（秒） |
| `targetDuration` | M3U8 目标分片时长 |

### 4.3 事件总线

| 事件名 | 触发方 | 数据结构 |
|--------|--------|----------|
| `video-found` | Sniffer | `{ url: string, type: string }` |

## 五、嗅探机制

### 5.1 钩子方式

| 方式 | 实现 |
|------|------|
| Fetch 劫持 | 包装 `unsafeWindow.fetch`，通过 `response.clone()` 读取 Content-Type |
| XHR 劫持 | 继承 `XMLHttpRequest`，在 `readystatechange` 中监听 `readyState === 4` |
| Performance 扫描 | 每 2 秒遍历 `performance.getEntriesByType('resource')` |

### 5.2 匹配规则

| 类型 | URL 匹配 | Content-Type 匹配 |
|------|----------|-------------------|
| M3U8 | `\.m3u8($|\?)` | `application/.*mpegurl` |
| MP4 | `\.mp4($|\?)` | `video/mp4` |
| MOV | `\.mov($|\?)` | `video/quicktime` |

### 5.3 去重策略

基于 URL 路径（去除 query string）去重，同一视频只触发一次通知。

## 六、下载机制

### 6.1 M3U8 下载流程

1. **解析 M3U8**：支持多码率主清单，自动选取最高带宽流
2. **获取密钥**：提取 `#EXT-X-KEY` 中的密钥 URL，提前缓存所有唯一密钥
3. **计算范围**：分片序号直接使用；时间范围通过 `timeList` 换算为分片下标
4. **并发下载**：多线程并发下载分片（默认 4 线程）
5. **AES 解密**：每个分片成功获取后执行 AES-128 解密（如有加密）
6. **拼接 TS**：按序拼接分片数据，直接生成 `.ts` 文件
7. **触发下载**：浏览器触发 Blob 下载

### 6.2 失败处理

- 每个分片最多重试 3 次，重试间隔指数退避（最大 10 秒）
- 失败分片生成空数据（0 字节），最终拼接时跳过
- 所有分片均失败时抛出明确错误
- 控制台打印详细的成功/失败统计日志

### 6.3 MP4 下载流程

- **移动端**：弹窗确认后调用浏览器原生下载器（省流量、不闪退）
- **桌面端**：通过 `GM_xmlhttpRequest` 下载后直接保存为文件
- 原生下载已触发时跳过后续处理，直接返回

```

    ↓

    ↓

    ↓

    ↓

    ↓
```

## 十、使用说明

### 10.1 安装

1. 安装 Tampermonkey / Violentmonkey 等用户脚本管理器
2. 新建脚本，粘贴 `m3u8嗅探下载器user.js.user.js` 全部内容
3. 保存并启用脚本

### 10.2 基本操作

1. 打开任意含视频的网页
2. 脚本自动启动网络嗅探（`document-start` 阶段注入）
3. 检测到视频资源时，左下角出现悬浮按钮
4. 点击按钮展开面板，查看已捕获的资源
5. 点击资源项展开下载设置
6. 选择范围模式（时间/切片）并输入区间
7. 点击"开始下载"执行下载

### 10.3 移动端适配

- 自动检测移动设备（Android/iOS 等）
- 移动端 MP4 下载优先调用浏览器原生下载器
- 面板位置适配安全区域（`env(safe-area-inset-bottom)`）

## 十一、注意事项

1. **线程数**：手机建议 2-4 线程，过高可能导致浏览器闪退
2. **加密视频**：AES-128 加密分片需要密钥 URL 可访问
3. **跨域限制**：部分视频源有 Referer/Origin 校验，可能导致请求被拒
4. **密钥获取**：密钥 URL 跨域时可能需要用户脚本的 `@connect` 授权
5. **选择目标**：下载前必须先点击列表项展开目标资源
6. **文件大小**：大体积视频建议在 Wi-Fi 环境下下载
7. **控制台日志**：打开浏览器开发者工具可查看详细的下载进度和错误信息
8. **Shadow DOM 降级**：移动端 Shadow DOM 失败时自动降级为普通 DOM
