# M3U8 资源嗅探器

> 视频嗅探下载器 (TS 分片 + ZIP 打包)

---

## 一、功能概述

| 功能 | 说明 |
|------|------|
| 网络嗅探 | 自动捕获页面中所有 m3u8/mp4 视频资源 |
| 实时监听 | Hook Fetch/XHR/Performance 接口，实时检测视频流 |
| 预览播放 | 新标签页播放完整流或单个 TS 分片 |
| 批量下载 | 支持分片范围/时间范围两种模式下载 |
| AES 解密 | 自动处理 AES-128 加密分片解密 |
| ZIP 打包 | 下载完成自动打包为 ZIP，含本地 m3u8 索引 |

---

## 二、模块架构

| 模块 | 职责 |
|------|------|
| UI (UI 面板) | 悬浮面板，展示嗅探结果、下载设置、预览入口 |
| Bus (事件总线) | 嗅探器与 UI 之间的解耦通信 |
| Sniffer (嗅探器) | Hook 网络请求，识别 m3u8/mp4 资源 |
| TaskRunner (任务入口) | 统一调度解析、下载、ZIP 打包 |
| VideoWriter (写入器) | 内存中维护 ZIP 文件流，最终触发浏览器下载 |
| AESCrypto (解密模块) | 针对 AES-128 加密分片执行解密 |

## 三、UI 面板说明

### 3.1 面板结构

- **左下角圆形按钮**：展开/收起面板
- **Tab 切换**：`M3U8` / `MP4` 两个标签页，分别展示对应类型资源
- **资源列表**：每项显示类型标签、文件名、复制/预览按钮
- **下载设置区**：选中资源后动态显示，支持范围配置和下载触发

### 3.2 M3U8 下载设置

| 元素 | 说明 |
|------|------|
| 切片范围 | 输入起始/结束分片序号（如 `10 - 50`） |
| 时间范围 | 输入 `HH:MM:SS` 格式时间区间（如 `00:00:30 - 00:02:00`） |
| 下载按钮 | 执行下载，显示实时进度百分比 |

### 3.3 MP4 下载设置

点击"下载 MP4"按钮执行下载；移动端优先调用浏览器原生下载器。

### 3.4 交互说明

| 操作 | 行为 |
|------|------|
| 点击列表项 | 选中资源，高亮显示（绿色背景 + 左边框） |
| 再次点击已选项 | 取消选中 |
| [复制] | 复制资源 URL 到剪贴板 |
| [预览] | 新标签页打开 HLS.js 播放器 |

### 3.5 预览页

解析 M3U8 后生成独立预览页，包含：
- 完整流播放器（HLS.js 自动加载 M3U8）
- 元信息展示：原始地址、加密状态、分片总数、总时长
- 分片列表表格：显示序号、序列号、时长、链接，支持点击单独播放

## 四、嗅探机制

| 钩子方式 | 实现 |
|---------|------|
| Fetch 劫持 | 包装 `unsafeWindow.fetch`，通过 `response.clone()` 读取 Content-Type |
| XHR 劫持 | 继承 `XMLHttpRequest`，在 `readystatechange` 中监听 `readyState === 4` |
| Performance 扫描 | 每 2 秒遍历 `performance.getEntriesByType('resource')` |

**匹配规则：**
- M3U8：URL 含 `.m3u8` 或 Content-Type 匹配 `mpegurl`
- MP4：URL 含 `.mp4` 或 Content-Type 匹配 `video/mp4`
- MOV：URL 含 `.mov` 或 Content-Type 匹配 `quicktime`

**去重策略：** 基于 URL 路径（去除 query string）去重，同一视频只触发一次通知。

## 五、下载机制

### 5.1 M3U8 下载流程

1. 解析 M3U8 文件（支持多码率主清单，自动选取最高带宽流）
2. 处理加密密钥（提取 `#EXT-X-KEY` 中的密钥 URL 和 IV）
3. 计算下载范围：切片下标直接使用；时间范围通过 `timeList` 换算为分片下标
4. 多线程并发下载分片（默认 4 线程）
5. 每个分片成功获取后执行 AES-128 解密（如有加密）
6. 按序写入 ZIP 文件，记录实际成功的文件名列表
7. 生成匹配 ZIP 内容的本地 `playlist.m3u8` 索引
8. 浏览器触发 ZIP 下载

**失败处理：**
- 每个分片最多重试 3 次，间隔 1 秒
- 失败分片跳过（不写入 ZIP），ZIP 和 playlist 保持对齐
- 所有分片均失败时抛出明确错误
- 控制台打印详细的成功/失败统计日志

### 5.2 MP4 下载流程

- **移动端**：弹窗确认后调用浏览器原生下载器（省流量、不闪退）
- **桌面端**：通过 GM_xmlhttpRequest 下载后直接保存
- 原生下载已触发时跳过 ZIP 打包，直接返回

### 5.3 ZIP 打包配置

| 配置项 | 值 | 说明 |
|--------|----|------|
| 压缩算法 | DEFLATE | 标准 ZIP 压缩 |
| 压缩级别 | 1 | 快速压缩，降低 CPU 和内存占用 |
| 文件格式 | Blob | 浏览器端内存中生成，零临时文件 |

## 六、核心接口

### 6.1 TaskRunner

```javascript
window.TaskRunner(url, type, btn, opt)
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `url` | string | 视频资源地址 |
| `type` | string | `'m3u8'` / `'mp4'` |
| `btn` | HTMLElement | 进度显示按钮 |
| `opt.startIdx` | number | 起始分片序号 |
| `opt.endIdx` | number | 结束分片序号 |
| `opt.beginSec` | number | 起始秒数 |
| `opt.endSec` | number | 结束秒数 |

### 6.2 parseM3u8

```javascript
parseM3u8(url) → { url, segments, timeList, totalDuration, targetDuration }
```

| 返回字段 | 说明 |
|----------|------|
| `url` | 最终解析的 M3U8 地址（可能经过多码率切换） |
| `segments` | 分片数组，每项含 `url / key / iv / seq / dur` |
| `timeList` | 时间索引，每项含 `idx / dur / tStart / tEnd` |
| `totalDuration` | 视频总时长（秒） |
| `targetDuration` | M3U8 目标分片时长 |

### 6.3 事件总线

| 事件名 | 触发方 | 数据结构 |
|--------|--------|----------|
| `video-found` | Sniffer | `{ url: string, type: string }` |

## 八、使用说明

### 8.1 安装

1. 安装 Tampermonkey / Violentmonkey 等用户脚本管理器
2. 新建脚本，粘贴 `m3u8嗅探器.js` 全部内容
3. 保存并启用脚本

### 8.2 基本操作

1. 打开任意含视频的网页
2. 页面加载后，嗅探器自动监听网络请求
3. 检测到视频资源时，左下角出现 🎬 面板（首次自动展开）
4. 点击列表项选中目标
5. 选择范围模式（切片/时间）并输入区间
6. 点击"下载选中资源"执行下载

### 8.3 移动端适配

- 自动检测移动设备，显示原生下载选项
- 原生下载：通过浏览器系统下载器保存，更稳定
- 脚本下载：通过 GM_xmlhttpRequest 下载后打包

## 十、注意事项

1. **线程数**：手机建议 2-4 线程，过高可能导致浏览器闪退
2. **加密视频**：AES-128 加密分片需要密钥 URL 可访问
3. **跨域限制**：部分视频源有 Referer/Origin 校验，可能导致请求被拒
4. **密钥获取**：密钥 URL 跨域时可能需要用户脚本的 `@connect` 授权
5. **选择目标**：下载前必须先点击列表项选中目标资源
6. **文件大小**：大体积视频建议在 Wi-Fi 环境下下载
7. **控制台日志**：打开浏览器开发者工具可查看详细的下载进度和错误信息
