# M3U8预览与正则生成 · 功能文档

> 版本：1.0 | 适用：Via/Kiwi手机浏览器 + Tampermonkey

## 功能概述

自动嗅探网页m3u8资源，新标签页打开视频预览播放器，通过进度条拖拽或手动输入选择多个时间段，自动生成用于1DM下载器的正则表达式。

## 架构设计

```
主页面（嗅探面板）                    预览页（新标签页）
┌─────────────────────┐              ┌──────────────────────────┐
│ 自动嗅探m3u8 URL    │   点击预览   │  HLS.js 视频播放器        │
│ 悬浮面板展示资源    │ ──────────→ │  进度条拖拽选时间段       │
│ 解析+缓存m3u8数据   │              │  手动输入时间段           │
│                     │              │  生成正则 + 复制          │
└─────────────────────┘              └──────────────────────────┘
```

## 使用流程

### 1. 嗅探m3u8

- 脚本自动劫持 `fetch`、`XHR`、`performance` 接口
- 发现 m3u8 资源后，右下角悬浮面板显示
- 点击展开资源详情

### 2. 打开预览页

- 点击 **🎬 预览+生成正则** 按钮
- 新标签页打开，自动加载 HLS.js 播放器
- 显示分片总数、总时长、加密状态

### 3. 选择时间段

#### 方式一：进度条拖拽

1. 点击进度条 → 设置起点
2. 再次点击 → 设置终点，自动添加时间段
3. 橙色标记显示已选范围
4. 可重复操作添加多个时间段

#### 方式二：手动输入

1. 输入框支持纯数字自动补冒号
   - `000120` → `00:01:20`
   - `1234` → `00:12:34`
2. 最多6位数字 `HHmmss`
3. 点击 **应用时间段** 生效

#### 时间段管理

| 操作 | 说明 |
|------|------|
| ➕ 添加时间段 | 从上一段结束时间开始，默认60秒 |
| 🗑️ 清空时间段 | 重置为默认 `00:00:00 - 00:01:00` |
| ✕ 删除 | 删除指定时间段，至少保留一个 |

### 4. 生成正则

1. 点击 **生成正则**
2. 每个时间段取首尾分片序号，生成范围正则
3. 多时间段用 `|` 拼接
4. 显示匹配的分片数量

### 5. 复制使用

| 按钮 | 功能 |
|------|------|
| 复制正则 | 复制正则表达式到剪贴板 |
| 复制匹配URL | 复制所有匹配的分片URL列表 |

## 正则生成规则

### 纯数字分片

从 URL 的 `/` 和 `.ts` 之间提取序号，按时间段分别生成：

```
时间段1: 分片 257471352 ~ 257471382
时间段2: 分片 257472161 ~ 257472242

生成正则：
2574713(?:5[2-9]|[6-7]\d|8[0-2])|257472(?:1(?:6[1-9]|[7-8]\d|9[0-9])|2(?:0[0-9]|[1-3]\d|4[0-2]))
```

### 非数字分片

用 `|` 连接所有文件名并转义：

```
(?:seg_a|seg_b|seg_c)
```

### 算法特点

- 递归处理进位，避免 `[6-4]` 等非法字符类
- 按公共前缀分段，生成紧凑正则
- 每个时间段独立生成，互不干扰

## 技术细节

### 核心函数

| 函数 | 功能 |
|------|------|
| `parseM3u8(url)` | 解析m3u8，返回segments+timeList |
| `timeToSegmentIndex(timeList, begin, end)` | 时间换算分片索引 |
| `buildNumericRangeRegex(min, max)` | 数字范围→正则 |
| `buildSameLengthRegex(minStr, maxStr)` | 等长数字范围→正则 |
| `buildSuffixRegex(minS, maxS)` | 递归处理后缀，处理进位 |
| `generateRegexFromSegments(segments)` | 提取首尾序号生成正则 |
| `numToHms(digits)` | 纯数字→自动补冒号格式化 |

### 数据传递

主页面解析 m3u8 后，将数据 JSON 序列化嵌入预览页 HTML，通过 `Blob URL` 打开新标签页：

```javascript
const segmentsJson = JSON.stringify({ url, segments, timeList, totalDuration });
const html = `... const videoData = ${segmentsJson}; ...`;
const blob = new Blob([html], { type: 'text/html' });
window.open(URL.createObjectURL(blob), '_blank');
```

### 时间输入处理

| 输入 | 输出 |
|------|------|
| `0` | `0` |
| `00` | `00` |
| `000` | `00:0` |
| `0001` | `00:01` |
| `00012` | `00:01:2` |
| `000120` | `00:01:20` |

编辑时不补零，避免退格删除时值被意外改变。

## 注意事项

1. **跨域问题**：m3u8 链接需允许跨域访问，否则解析失败
2. **HLS.js 依赖**：预览页通过 CDN 加载 `hls.js`，需网络可用
3. **时间段校验**：开始时间必须早于结束时间
4. **正则有效性**：算法确保生成的正则无 `[x-y]` 倒序等非法语法
5. **去重处理**：多时间段重叠的分片自动去重，不会重复匹配
