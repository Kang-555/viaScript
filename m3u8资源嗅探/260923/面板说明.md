## 🔍 嗅探机制（v4.2）

参考独立脚本 `视频嗅探.user.js` 的多通道架构，**7 条通道并行嗅探 m3u8**：

| # | 通道 | 原理 | 优先级 |
|---|------|------|--------|
| 1 | **fetch hook** | 劫持 `window.fetch`，从 URL 和 Content-Type 同时匹配 m3u8 | 主 |
| 2 | **XMLHttpRequest prototype** | 直接替换 `XMLHttpRequest.prototype.open`（比 class 继承更通用，不怕站点覆盖构造函数） | 主 |
| 3 | **PerformanceObserver** | 持续监听 `resource` 类型条目，**SPA 路由切换后的新请求也能抓到** | 补 |
| 4 | **DOM video/source 扫描** | 遍历 `<video>` 和 `<source>` 的 `src` 属性，加 MutationObserver 监听动态注入 | 补 |
| 5 | **GM_webRequest** | 油猴底层网络拦截，**代码完全绕过 fetch/XHR 也能捕获** | 兜底 |
| 6 | **pushState/replaceState 劫持** | SPA 路由切换时自动重新捕获 Referer + 重扫 DOM | 增强 |
| 7 | **iframe postMessage** | iframe 中嗅探到的 m3u8 通过 `postMessage` 传给顶层窗口 | 跨域 |

**Referer 自动捕获**：
- 首次加载 / fetch 发起 / SPA 路由切换 时均更新 `state.referer = location.href`
- 生成命令时自动填入 `-H "Referer: ..."` 避免手动复制

**去重机制**：`sniffedSet` 以 `url.split('?')[0]` 为 key 去重，`visitedRes` 供 PerformanceObserver 去重。

## Tab 3：生成（命令预览 + 操作）

```
┌──────────────────────────────────────────┐
│ 嗅探          时间段          生成       │
├──────────────────────────────────────────┤
│ 📌 playlist_720p.m3u8                   │
│    00:30:00 - 00:30:23                  │  ← 时间摘要
│    文件名: 某视频标题                    │  ← 文件名摘要
│ ─────────────────────────────────────── │
│ ▶ 命令预览                              │
│ ┌─────────────────────────────────────┐ │
│ │ ~/test/N_m3u8DL-RE "https://...m3u8"│ │
│ │   -H "User-Agent: Mozilla/5.0 ..."  │ │  ← v4.2 新增固定 UA
│ │   -H "Referer: https://当前页面URL" │ │  ← v4.2 自动捕获填入
│ │   --custom-range "00:30:00-00:30:23"│ │  ← 有时间才输出这行
│ │   --thread-count 8                  │ │
│ │   --download-retry-count 5          │ │
│ │   --no-log                          │ │
│ │   --save-dir ~/storage/downloads    │ │
│ │   --save-name "某视频标题"           │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ [📋 复制]            [💾 下载 nm_tpl.txt] │  ← 等宽按钮
│                                         │
└──────────────────────────────────────────┘
```

**未选链接时**：
```
居中显示: ⚠️ 请先在嗅探 tab 选择一个 m3u8
```

**命令预览框**：
```
textarea readonly, width:100%, min-height:80px
background:#0a0a1a, color:#6f9, border:1px solid #333
font-family:monospace, font-size:10px
任何输入变化 → 即时重渲染
```

**全程下载时的命令**（时间框清空 → `--custom-range` 行自动省略）：
```shell
~/test/N_m3u8DL-RE "https://...m3u8" \
  -H "User-Agent: Mozilla/5.0 (Linux; Android 14; Pixel 8) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/129.0.0.0 Mobile Safari/537.36" \
  -H "Referer: https://当前页面URL自动填入" \
  --thread-count 8 \
  --download-retry-count 5 \
  --no-log \
  --save-dir ~/storage/downloads \
  --save-name "某视频标题"
```

**带时间段时的命令**：
```shell
~/test/N_m3u8DL-RE "https://...m3u8" \
  -H "User-Agent: Mozilla/5.0 (Linux; Android 14; Pixel 8) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/129.0.0.0 Mobile Safari/537.36" \
  -H "Referer: https://当前页面URL自动填入" \
  --custom-range "00:30:00-00:30:23" \
  --thread-count 8 \
  --download-retry-count 5 \
  --no-log \
  --save-dir ~/storage/downloads \
  --save-name "某视频标题"
```

**v4.2 命令模板说明**：
| 行 | 内容 | 来源 |
|----|------|------|
| 第 1 行 | `~/test/N_m3u8DL-RE "<m3u8>"` | 用户选中的嗅探链接 |
| 第 2 行 | `-H "User-Agent: ..."` | **固定值**：安卓 Chrome 129 UA（避免站点拦截默认 UA） |
| 第 3 行 | `-H "Referer: ..."` | **自动捕获**：当前页面 `location.href` |
| 可选行 | `--custom-range "HH:MM:SS-HH:MM:SS"` | 用户输入，空则省略 |
| 固定行 | `--thread-count 8` / `--download-retry-count 5` / `--no-log` / `--save-dir ~/storage/downloads` / `--save-name` | 硬编码 |

> 所有行末尾都有 `\`，shell 中换行续行（最后一行 `--save-name` 末尾不带 `\`），粘贴即可执行。

**操作按钮**：
```
[📋 复制]    主色背景 #4caf50, color #000 → GM_setClipboard → toast
[💾 下载]    transparent + border #4caf50 + color #4caf50 → Blob + a.click()
```

## 三个 Tab 的数据流向

```
嗅探 tab                    时间段 tab                   生成 tab
┌─────────────┐  选中链接   ┌─────────────────┐  填完参数   ┌─────────────────┐
│ 7 通道嗅探  │──────────→│ 时间输入        │──────────→│ 多行续行命令    │
│ 列表 → 点击  │  自动跳转  │ 文件名输入(text)│  切「生成」 │ 含 UA + Referer │
│ 手动粘贴    │            │                 │  tab即可    │ 复制 / 下载     │
└─────────────┘            └─────────────────┘            └─────────────────┘

任何 tab 输入变化 → 命令预览实时重算
```

## 交互事件一览

| 事件 | 行为 |
|------|------|
| 嗅探到新 m3u8 | 自动追加到列表 |
| 点击列表项 | 选中 → 自动跳到「时间段」tab |
| 点「手动粘贴」 | prompt → 添加并选中 → 跳到「时间段」tab |
| 点击 tab | 切换内容区；切到「生成」时自动重渲染命令预览 |
| 点 `×` | 隐藏面板（嗅探 hook 保留） |
| 时间输入变化 | 重算命令预览 |
| 文件名输入变化(textarea) | 重算命令预览 |
| 点「复制」 | `GM_setClipboard` → toast |
| 点「下载」 | Blob + a.click() → 浏览器自动重命名 |

## 文件输出规则

**每个 txt 文件包含 1 条多行续行命令**（带 `\` 的 shell 格式）  
**一个时间段**（`--custom-range` 或省略）  
文件名固定 `nm_tpl.txt`，浏览器重名自动加序号 → `nm_tpl (1).txt`、`nm_tpl (2).txt`...  
Termux 端 `~/a` 按文件名排序读取执行即可。
